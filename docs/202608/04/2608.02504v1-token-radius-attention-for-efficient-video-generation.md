## 摘要
视频扩散变换器（VDiTs）能够实现高保真生成，但密集的3D自注意力带来了二次方成本。现有的头部级和块级稀疏方法在查询之间共享计算预算，忽略了令牌特定的注意力需求。我们观察到，保留密度因查询而异，但与注意力熵呈对数线性相关，而主导交互形成以查询为中心的邻域，且半径依赖于令牌。基于这些发现，我们提出了令牌半径注意力（TRA），这是一种免训练框架，将查询熵映射为解析令牌预算，并无需显式键排序即可将其转换为时间衰减半径。融合熵提取、预热复用和块稀疏掩码构建进一步减少了开销。在七种Wan2.1、Wan2.2和HunyuanVideo T2V/I2V配置中，TRA仅保留9%-19%的注意力交互，实现了1.56倍至2.05倍的加速，并保持了有竞争力的生成质量。代码可在https://github.com/IF-LAB-PKU/Token-Radius-Attention获取。

## Abstract
Video Diffusion Transformers (VDiTs) enable high-fidelity generation but incur quadratic cost from dense 3D self-attention. Existing head- and block-level sparse methods share computation budgets across queries, overlooking token-specific attention demand. We observe that retained density varies across queries yet correlates log-linearly with attention entropy, while dominant interactions form query-centered neighborhoods with token-dependent radii. Based on these findings, we propose Token Radius Attention (TRA), a training-free framework that maps query entropy to an analytic token budget and converts it into a temporally decayed radius without explicit key ranking. Fused entropy extraction, warm-up reuse, and block-sparse mask construction further reduce overhead. Across seven Wan2.1, Wan2.2, and HunyuanVideo T2V/I2V configurations, TRA retains only 9-19% of attention interactions and achieves 1.56x-2.05x speedup with competitive generation quality. Code is available at https://github.com/IF-LAB-PKU/Token-Radius-Attention.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：视频扩散 Transformer（VDiTs）在高质量视频生成中取得了显著成功，但代价是密集 3D 自注意力带来的 **O(N²) 二次方计算开销**，随着视频时长和分辨率的提升，注意力计算成为推理部署的主要瓶颈。
- **现有方法的不足**：既有稀疏注意力方法可归为两类——**头部级方法**（如 SVG、Radial Attention）为每个注意力头分配固定的空间/时间模式，**块级方法**（如 SVG2、SpargeAttn）选择重要的查询—键块对。两者本质上都在一个头或块内**共享同一计算预算**，默认组内所有查询的注意力需求一致。
- **核心矛盾**：softmax 是逐查询独立归一化的，因此不同查询所需的关键键（key）数量天然是 token 特定的——集中型查询只需少量键，弥散型查询则需要大量键。共享预算导致对集中型查询浪费算力、对弥散型查询丢失关键信息。
- **本文回答的问题**：能否在 **token 粒度**上实现自适应的稀疏注意力分配，同时保持可高效执行的**规则化结构化稀疏**？

## 2. 方法论

### 2.1 核心思想：Entropy-to-Budget-to-Radius 管线

TRA 是一个**免训练**框架，核心逻辑是三步走：**熵预测预算 → 预算转化为半径 → 半径构造稀疏掩码**。其可行性建立在两个经验洞察之上：

- **洞察 I：Token 特定注意力稀疏性**。保留密度（retained density，即达到目标注意力质量 τ 所需的最小键比例）在同一层/同一头内跨查询差异可达数量级，且 **log Bᵢ 与注意力熵 Hᵢ 近似线性相关**（R²=0.940–0.966），熵因此可作为免训练的逐查询预算信号。
- **洞察 II：Token 半径注意力模式**。高注意力键围绕查询形成近似**圆形邻域**，归一化注意力概率随二维空间距离呈近似**指数衰减**（R²=0.791），且半径在不同查询、头、层之间差异显著。因此可将标量预算转化为几何上有意义的圆形支撑。

### 2.2 关键技术细节

1. **熵到预算映射（Entropy-to-Budget）**
   - 引入熵等效均匀分布近似：每个查询的注意力分布等效视为在 exp(Hᵢ) 个键上均匀分配质量。
   - 由此得到**解析式预算公式**：目标注意力质量为 τ 时，所需键数为 \(\hat{K} = \lceil \tau \exp(H_i) \rceil\)，保留比例为 \(\hat{B} \approx \tau \exp(H_i) / N\)。
   - 该公式无需对键进行排序或训练预测器，纯解析、单调。

2. **预算到半径构建（Budget-to-Radius）**
   - 引入时间衰减因子 ϕ(δ)=exp(−γδ)，定义第 t 帧的半径为 \(r_{i,t} = r_i \cdot \phi(|t - f_i|)\)。
   - 基础半径通过连续面积近似初始化：\(r_i = \sqrt{\hat{K} / [\pi \sum_t \phi^2(|t-f_i|)]}\)，再通过边界感知的离散格点计数修正，选取最小的候选半径使离散支撑达到目标键数。
   - 最终逻辑掩码为 \(M_{ij} = \mathbb{I}[d_s(i,j) \le r_i \phi(|f_j - f_i|)]\)，等效于在注意力矩阵中加入 −∞ 掩码。文本键始终全可见。

3. **高效掩码构建与熵提取**
   - **Flash Radius Mask Kernel**：将每帧 H×W 划分为 tile，按 tile-major 重排 token，使邻域 token 连续，减少碎片化块。融合距离计算、半径比较、块剪枝与 token 投票于一个 CUDA kernel，输出块级掩码供 FlashInfer 块稀疏注意力执行。
   - **Fused Attention Entropy Kernel**：将熵重写为 \(H_i = \log Z_i - \sum_j p_{ij} s_{ij}\) 的形式，在在线 softmax 过程中同步累积熵，避免物化完整注意力矩阵或二次扫描。
   - **预热复用**：仅在前 25% 去噪步（warm-up）中执行稠密注意力并提取熵，后续稀疏步直接复用预算、半径和掩码，基于跨步熵稳定性观察（最小余弦相似度 0.945）。

## 6. 主要结论与发现

1. **验证了 token 特定注意力稀疏性**：保留密度随查询差异可达数量级，且与熵呈强 log-linear 关系（R²≈0.94–0.97），跨模型（Wan 与 HunyuanVideo）和跨去噪阶段稳定存在。
2. **验证了 Token Radius 注意力模式**：注意力随空间距离指数衰减，主导交互构成以查询为中心、半径因查询而异的圆形邻域。
3. **TRA 效率显著**：仅保留 **9%–19%** 的注意力交互，FLOPs 较稠密模型降低 62%–67%，实现 **1.56×–2.05×** 端到端加速，在低密度下 PSNR 与注意力召回明显优于既有方法。
4. **TRA 质量有竞争力**：在全部 7 个配置上获得稀疏方法中最高的 VBench Overall 分数；在 Wan2.1-14B T2V 上几乎追平稠密注意力（87.39 vs 87.41）。
5. **定制内核有效**：掩码构建与熵提取的融合内核分别实现 10.35× 和 12.34× 相对朴素实现的加速，使辅助开销不再是瓶颈。

## 7. 优点

- **方法设计层面的亮点**：
  - 以 **token 为粒度**进行稀疏分配，直接对齐 self-attention 的逐行归一化本质，突破了头级/块级共享预算的局限。
  - **免训练、零额外参数**：熵到预算为纯解析映射，无需学习预测器，推理时通过 lookup table 实现边界感知半径选择。
  - **Adaptivity–Efficiency 平衡**：token 级自适应通过时间衰减半径和 tile-major 重排转化为规则块稀疏结构，兼顾灵活性与硬件友好性。
  - **双洞察有据可依**：log-linear 熵-密度关系和空间指数衰减模式均在多个模型上验证（Wan R²≈0.94–0.97，Hunyuan R²≈0.98–0.99），非单点观测。
  - **系统级工程完整**：融合熵核、掩码构建核、FlashInfer 后端对接、预热复用等形成了完整的推理加速方案，而非仅停留在算法层面。
- **实验层面的优点**：
  - 对基线的对比既包含质量（VBench）、效率（FLOPs/延迟/密度）和保真度（PSNR/SSIM/LPIPS）三维指标。
  - 分布性分析（表 4、图 9）对比了多种分布假设（Uniform、Lognormal、Gamma、Weibull）下的预算误差，验证了 uniform 近似的合理性，增加了方法论的理论可信度。
  - 跨模型验证（Wan2.2 与 HunyuanVideo）提供了洞察的泛化证据。

## 8. 不足与局限

- **结构模式的约束**：TRA 的支撑集被限制为预定义的、基于距离的时空模式（固定时间衰减 γ 和圆形空间邻域），无法充分捕捉内容相关的长程交互（如跨帧的物体对应关系、非局部运动、场景依赖的注意力结构）。作者在 Limitations 中承认了这一点。
- **块稀疏后端的固有冗余**：当前实现仍依赖 FlashInfer 的块稀疏注意力后端，在选中的块内保留了一部分无用 token 计算（实验中的密度 9–19% 是平均密度，若按块粒度看实际执行开销更高）。作者指出现有内核缺乏专门的 token 级稀疏执行，仍是效率上可优化的方向。
- **分布近似有偏差**：uniform 等效支撑近似在完全均匀分布时最优，但真实注意力分布往往更加尖峰；虽然 MAE 仅比最优解析映射高 0.016，但高熵区间的预测偏向保守（过估预算），高熵部分仍有改进空间。
- **Radial 基线对比公平性**：Radial Attention 因自身加速策略限制使用了不同分辨率/帧数，跨方法的严格公平对比无法完全保证。
- **静态复用假设**：TRA 假设预热阶段估计的熵/掩码在后续去噪步骤中保持稳定（跨步余弦相似度 ≥0.945），但如果生成任务的去噪轨迹出现较大偏移，复用的掩码可能过时。实验表明该假设在该数据集上基本成立，但鲁棒性边界未充分探索。
- **超参数敏感性**：γ（时间衰减因子）需按模型手工调节（Wan 用 0.6，HunyuanVideo 用 0.95），τ（目标注意力质量）的选择对质量-效率权衡有直接且显著的影响，但文中未给出 τ 的自动化选择策略。
