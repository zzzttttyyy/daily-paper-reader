## 摘要
无训练特征预测通过预测跳过的去噪步骤中的特征来加速扩散采样。近期工作主要集中于设计更强的预测器。然而，预测误差在不同步骤间变化剧烈，开环缓存在每个跳过步骤完全信任预测。这种固定信任正是加速变得激进时崩溃的原因。缺失的问题不仅是如何更好地预测，还包括何时以及多大程度上信任预测。我们证明可靠性可以从缓存本身观察到。当特征轨迹平滑时，两个预测达成一致；当预测变得困难时，它们出现分歧。它们的分歧是一种廉价的运行时信号，且不需要额外的去噪器评估。基于这一信号，我们提出了RACER，一种具有两种响应的无训练闭环控制器。它持续将不确定的预测收缩至最后计算的特征。在风险最高的步骤，RACER刷新特征，并通过跳过后续安排的评估来补偿增加的评估。我们推导了收缩的确定性误差界，并跨加速场景实证评估了其有效性和紧致性。在相同数量的去噪器评估下，RACER在SD3.5-Large、FLUX.1-dev、Wan2.1-14B和HunyuanVideo上，在DrawBench、VBench和COCO上均优于最强的开环基线。在SD3.5上，我们进一步表明RACER在相等质量下采样更快。RACER同样能泛化至不同的预测设计。例如，它恢复了在Taylor基上损失的大部分质量。这些结果表明，可靠的扩散加速也取决于预测的使用方式。代码可在 https://github.com/LiZaiyuan0619/RACER 获取。

## Abstract
Training-free feature forecasting accelerates diffusion sampling by predicting features at skipped denoising steps. Recent work has mainly focused on designing stronger forecasters. Yet forecast error varies sharply across steps, and open-loop caches trust the forecast in full at every skipped step. This fixed trust is what breaks as acceleration turns aggressive. The missing question is not only how to forecast better, but when and how much to trust a forecast. We show that reliability can be observed from the cache itself. Two forecasts agree where the feature trajectory is smooth, and they diverge where prediction turns hard. Their disagreement is a cheap runtime signal, and it costs no extra denoiser evaluation. Based on this signal, we introduce RACER, a training-free closed-loop controller with two responses. It continuously shrinks uncertain forecasts toward the last computed feature. At the riskiest steps, RACER refreshes the feature and repays the added evaluation by skipping a later scheduled one. We derive a deterministic error bound for the shrinkage and empirically evaluate its validity and tightness across acceleration regimes. At the same number of denoiser evaluations, RACER improves the strongest open-loop baseline across SD3.5-Large, FLUX.1-dev, Wan2.1-14B, and HunyuanVideo on DrawBench, VBench, and COCO. On SD3.5, we further show that RACER samples faster at equal quality. RACER generalizes across forecasting designs as well. For example, it recovers much of the quality lost on a Taylor base. These results show that reliable diffusion acceleration also depends on how forecasts are used. Code is available at https://github.com/LiZaiyuan0619/RACER

## 1. 核心问题与研究动机

扩散模型在图像和视频生成领域占据主导地位，但其采样过程极其缓慢：生成一个样本需要调用数十次甚至数百次大型去噪器，这一调用次数（NFE, Number of Function Evaluations）直接决定采样耗时。无训练特征缓存（Training-free Feature Caching）是当前最主要的加速手段之一，其核心思路是仅在部分步骤运行去噪网络，其余被跳过的步骤通过预测器从缓存中推算缺失特征。

然而，现有工作存在一个关键盲区：**无论预测器本身多强（从局部 Taylor 展开到全局 Chebyshev 多项式拟合），预测结果在运行时都被“全权信任”地使用，没有对预测可靠性进行任何检查。** 由于预测误差在不同采样步骤间分布极不均匀——在特征轨迹平滑处误差小而急剧弯折处误差陡增——这种固定信任机制在加速变得激进时会导致质量崩塌。

论文提出的核心问题不再是"如何更好地预测"，而是：

> **在每个步骤，应多大程度信任给定的预测？何时完全不应信任？**

作者发现了一个关键洞见：**预测失败的方式会在缓存中留下痕迹。** 不同预测器携带不同偏差，在预测困难时各自漂移。因此，两个不同的预测器在平滑区域意见一致，在困难区域产生分歧。这种**分歧信号（disagreement）** 可以仅从缓存中计算，无需额外的去噪器评估，便能高可靠地标识高风险步骤。

## 2. 方法论：RACER 闭环控制器

### 2.1 核心思想

作者提出 **RACER（Reliability-Aware Closed-loop controller with Exact Repay，可靠性感知精确偿还闭环控制器）** ，将特征缓存从"开环盲信"转变为"闭环可控"。RACER 保持基础预测器不变，仅在运行时根据可靠性信号动态调整对预测的信任程度。该方法在数学上被表达为元组 `(U, V, f, g, π)`，其中 `U` 为计算步骤集（运行去噪器），`V` 为跳过步骤集，`f` 为基础预测器，`g` 为观测预测器，`π` 为控制策略——它独立于具体预测器的选择。

### 2.2 关键组件

**① 可靠性信号：预测分歧**

在每个跳过步骤，除基础预测 `ĥₜ` 外，额外用一个观测器 `ĝₜ`（默认采用局部 Taylor 展开规则，与基础预测器的 Chebyshev 全局拟合形成不同偏差类型）从同一缓存做出第二个预测。相对分歧定义为：

```
rₜ = ‖ĥₜ − ĝₜ‖ / ‖ĥₜ‖
```

该信号的计算仅需 O(F) 算术运算（F 为特征维度），在 SD3.5 上的额外延迟约为 2%，且**无需额外去噪器评估**。其有效性基于两个条件（论文有理论证明）：基础预测器误差有界（公式4）且预测器与观测器误差相关性低（公式5）。Chebyshev 与 Taylor 组合在误差相关系统计为 0.17–0.44，保证了信号的可靠性。

**② 响应一：连续信任收缩（Shrinkage）**

当信号显示预测不确定时，RACER 将输出特征在锚点（最近已计算特征 `aₜ`）与预测值之间连续收缩：

```
ŷₜ = aₜ + κₜ(ĥₜ − aₜ)
```

信任系数 `κₜ` 随跳步距离 `kₜ` 增大和分歧 `rₜ` 增大而单调衰减：

```
κₜ = exp(−λ·max(kₜ−1,0)) · σ(β(θ_κ − rₜ))
```

其中 σ 为 Sigmoid 函数。极端情形 κ=0（纯复用锚点）和 κ=1（全信预测）恰好对应现有方法，RACER 位于两者之间，且由实时信号引导。

**③ 响应二：精确刷新-偿还（Refresh-and-Repay）**

当分歧超过刷新阈值（`rₜ > θ_ref`），表示该步骤的预测已不可信。此时 RACER 花一次真实去噪器评估以重新计算特征，然后通过从后续可偿还步骤集 `R ⊆ U` 中**删除一个已排定的步骤**来"偿还"这一次评估。债务计数器追踪未偿还的刷新，确保每个刷新都有未来的步骤与之匹配。因此，**每条提示词的 NFE 精确等于基础方法的 NFE**（命题3的构造性保证），预算不变而质量提升。

### 2.3 理论性质

| 命题 | 内容 | 意义 |
|------|------|------|
| 命题1：误差界 | 对任意 κ∈[0,1]，收缩输出误差 ≤ κ·B_f + (1−κ)·B_h（B_f、B_h 分别为预测器和锚点误差上界） | 分布无关的确定性误差界；实证中覆盖每个步骤，误差/界比值平均 0.932 |
| 命题2：MSE 最优收缩 | 最优 κ* 为两个相关估计的最优组合，与预测器/锚点误差二阶矩及其相关性有关；不相关时退化为逆 MSE 加权 | 为信任结构提供最优性依据 |
| 命题3：精确预算 | 每条提示词的去噪器评估数恒等于 |U| | 构造性保证预算守恒 |

### 2.4 校准方式

控制器标量（λ、β、θ_κ、θ_ref）通过一条短离线轨迹确定，无需训练、不修改去噪器。图像侧参数可从 SD3.5 直接迁移至 FLUX（信任阈值仅变化 4.7%）。固定规则：α≤0.75 用步坐标，α≥3.0 用 logSNR 坐标。

## 6. 主要结论与发现

1. **预测不可靠性可从缓存内部观测。** 两个带不同偏差的预测器的分歧是预测困难的高可靠性指标（AUROC 0.94），远超此前依赖输入侧信号的缓存方法（0.77）。

2. **闭环控制优于开环盲信。** 在匹配 NFE 下，RACER 在全部 4 个模型、全部加速档位和 3 个评测基准上，PSNR 和 SSIM 全面超越最强开环基线 Chebyshev，任务指标（ImageReward、CLIP、VBench）匹配或改善。

3. **质量提升可转换为速度收益。** 在 SD3.5 上，RACER 达到实测 2.6–5.4× 相对 50 步采样器的加速比，且以 0.76× 延迟和 0.72× NFE 即可达到基线的最高质量——即在相等质量下更快，在相等 NFE 下更好。

4. **机制独立于预测器设计。** 在 Taylor 基上恢复高达 3.83 dB 质量损失；观测器也可替换；图像侧参数可从 SD3.5 迁移至 FLUX，信任阈值仅变化 4.7%。这表明可靠加速的关键更多在于**预测的使用方式**而非预测器本身。

5. **刷新集中在高误差步骤。** 当允许还款时，刷新出现在高误差排名处，说明计算资源被有效部署在关键位置。

6. **两个响应协同分工。** 刷新策略主导温和加速档位，收缩策略在激进档位持续增益，两者结合在所有档位最佳。

## 7. 方法优点

1. **问题重新定义**：将特征缓存从"预测器设计"问题重新定义为"预测信任管理"问题，揭示了此前被忽视的盲区，为后续研究打开新方向。

2. **信号零成本**：分歧信号完全从缓存内部计算，无需额外去噪器评估、无需修改输入侧或网络内部结构，额外延迟仅约 2%。

3. **精确预算保证**：刷新-偿还机制在理论上（命题3）和实证上（20 配置 × 200 提示词从未偏差）保证了逐提示词 NFE 恒定，使得所有对比在公平基准下进行。

4. **理论支撑扎实**：三个命题分别提供确定性误差界、MSE 最优收缩依据和精确预算保证，且误差界经验证具紧致性（误差/界比 0.932，Spearman 相关 0.997）。

5. **免训练、易迁移**：控制器的标定仅需一条短离线轨迹，无需训练、无需修改去噪器；参数可跨模型迁移。

6. **正交兼容现有方法**：RACER 可叠加在任何特征缓存预测器之上，充当通用"信任层"，具有广泛适用性。

7. **全面的实证验证**：覆盖图像/视频双模态、5 个加速档位、多粒度消融（信号、组件、预测器、观测器），实验设计严谨。

2. **LPIPS 指标的偶发损失**：虽然 PSNR/SSIM 全面领先，但 LPIPS（感知相似度）在部分场景低于基线，论文未对其原因做深入分析。这可能暗示收缩操作在某些感知维度上的副作用。

3. **视频模型阈值仍需逐档校准**：图像侧参数可跨模型迁移，但视频侧阈值仍需每条模型和档位单独校准，降低了即插即用性。

4. **信号机制依赖观测器质量**：分歧信号的有效性依赖于预测器-观测器对的"低误差、弱相关"条件。虽然论文展示了 Taylor 和 FoCa 是良好观测器，但对任意预测器最优观测器的选择策略尚未系统化。

5. **跨模型迁移验证有限**：仅验证了 SD3.5→FLUX 方向，且只报告了信任阈值的 4.7% 变化；更多跨模型迁移情形（如对比视频模型间、分布差异更大的模型对）有待验证。

6. **收益在高质量基线下递减**：论文明确指出，当基础预测器已紧密贴近参考时，增益较小。随着预测器的持续增强，RACER 的增量优势可能收窄。

7. **刷新-偿还机制的时序约束**：仅在"刷新时有后续可偿还步骤存在"时才允许刷新，因此采样后期步骤只能依赖收缩响应，无法享受刷新，存在结构性性能天花板。

8. **应用范围局限**：当前主要聚焦于扩散采样推理加速。对于多步采样的其他任务（如逆问题求解）或非扩散生成模型的适用性未做探索。
