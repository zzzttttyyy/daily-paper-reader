## 摘要
尽管文本到图像（T2I）扩散模型已取得显著成功，但多对象场景中的精确空间与朝向控制仍是一个持续存在的挑战。现有方法要么依赖计算成本高昂的密集3D地图，要么遭受严重的属性泄漏和“剪切粘贴”伪影。为解决这些局限，我们提出PoseAdapter，一种用于高保真2.5D可控图像生成的轻量级框架。它不采用密集空间地图，而是通过一种高效的条件布局建立精确的空间-角度锚点：包含独立对象描述、2D边界框和3D角度。为解决严格实例隔离与全局一致性之间的生成权衡，我们引入了一种上下文感知的双流表示。通过并行掩码与非掩码路径，将局部对象令牌和关系增强的场景令牌注入现代MM-DiT架构的视觉流中，PoseAdapter在保持对象间自然关系和场景级一致性的同时消除了属性泄漏。为支持这一范式，我们构建了OrientLayout，一个具有标准化2.5D标注和实例级解耦语义的高质量数据集。大量实验表明，PoseAdapter在空间准确性、朝向精度和多对象视觉保真度方面均优于最先进的基线方法。代码和数据集将在 https://github.com/cyf23/PoseAdapter 上提供。

## Abstract
While Text-to-Image (T2I) diffusion models have achieved remarkable success, precise spatial and orientational control in multi-object scenes remains a persistent challenge. Existing methods either rely on computationally expensive dense 3D maps or suffer from severe attribute leakage and "cut-and-paste" artifacts. To address these limitations, we propose PoseAdapter, a lightweight framework for high-fidelity 2.5D controllable image generation. Instead of dense spatial maps, it establishes precise spatial-angular anchors using an efficient condition layout: individual object captions, 2D bounding boxes, and 3D angles. To resolve the generative trade-off between strict instance isolation and global coherence, we introduce a Context-Aware Dual-Stream Representation. By injecting local object tokens and relation-enriched scene tokens into the visual stream of modern MM-DiT architectures via parallel masked and unmasked pathways, PoseAdapter eliminates attribute leakage while preserving natural inter-object relationships and scene-level coherence. To support this paradigm, we construct OrientLayout, a high-quality dataset featuring standardized 2.5D annotations and instance-level decoupled semantics. Extensive experiments demonstrate that PoseAdapter outperforms state-of-the-art baselines in spatial accuracy, orientational precision, and multi-object visual fidelity. Code and dataset will be available at https://github.com/cyf23/PoseAdapter.

# PoseAdapter 论文总结

## 1. 核心问题与研究动机

**核心问题：** 文本到图像（T2I）扩散模型虽然在生成质量上取得了巨大成功，但在**复杂多对象场景**中，用户仍然难以精确控制每个对象的**空间位置**、**尺寸大小**和**三维朝向**。

**现存方法的局限：**

- **依赖密集3D表示**：如深度图、CNOCS地图等，计算成本高、交互编辑不便（如 LOOSECONTROL、SceneDesigner）。
- **属性泄漏（Attribute Leakage）**：在多对象生成中，一个对象的颜色、纹理或身份容易"渗透"到相邻对象上，导致语义纠缠。
- **"剪切粘贴"伪影**：为隔离对象而采用的硬边界掩码虽然能防止属性泄漏，但忽视了对象间的相互关系，导致缺乏自然遮挡、相对深度和光照一致性。
- **现有方法的各自缺陷**：
  - Zero-1-to-3：仅限单对象，无法处理复杂场景；
  - CompassControl：仅限单角度操作，依赖合成数据，泛化受限；
  - ORIGEN：依赖测试时优化（one-step flow model），无法与标准多步扩散集成；
  - SceneDesigner：依赖稠密CNOCS图，交互不便且复杂构图中易出现几何偏差。

**PoseAdapter 的目标：** 在不使用稠密3D图的前提下，实现多对象场景中精确的空间布局控制和三维朝向控制，同时消除属性泄漏并保持全局场景一致性。

## 2. 方法论

### 2.1 总体框架

PoseAdapter 采用"**2.5D轻量条件布局 + 上下文感知双流表示 + MM-DiT视觉流注入**"的技术路线。整体流程分为三个阶段：条件编码 → 双流表示构建 → 扩散模型注入。

### 2.2 2.5D 条件布局与编码

每个对象 $o_i$ 用三元组 $(c_i, b_i, a_i)$ 表示：

- **$c_i$（对象描述）**：经冻结的CLIP文本编码器提取特征，将细粒度属性（材质、颜色、动作）绑定到特定实体，从条件层面缓解语义纠缠；
- **$b_i \in \mathbb{R}^4$（2D边界框）**：经16频带傅里叶位置编码 + 两层MLP（SiLU + LayerNorm），得到256维嵌入；
- **$a_i \in \mathbb{R}^3$（3D角度）**：由方位角、极角、旋转角组成，映射到三角连续空间 $[\sin(a_i), \cos(a_i)] \in \mathbb{R}^6$，经三层MLP得到256维嵌入。

最终通过融合网络生成统一的初始对象令牌：
$$t_i^o = \text{MLP}_{\text{fusion}}([f_i^{\text{caption}}, f_i^{\text{box}}, f_i^{\text{angle}}])$$

### 2.3 上下文感知双流表示

**动机：** 单独使用掩码方式生成对象会导致"剪切粘贴"伪影；完全去除掩码则会导致属性泄漏。因此构建互补的双流表示：

- **局部对象令牌 $T^o$**：直接编码每个对象的独立属性与空间-角度配置；
- **场景令牌 $T^s$**：将 $T^o$ 输入多层Scene Transformer（自注意力），使每个对象感知其他对象的语义和几何配置，得到关系增强的场景令牌。

### 2.4 模态解耦的双流注入

- **注入位置**：仅注入现代MM-DiT架构的**视觉流**（$H^{\text{img}}$），保持文本流（$H^{\text{txt}}$）不受干扰；
- **局部流（掩码）**：使用动态布局掩码M约束注意力范围，强制实例边界：
  $$O^{\text{local}} = \text{Attn}(Q^{\text{img}}, \text{RMSNorm}(T^o W_k^{ip}), T^o W_v^{ip}, M)$$
- **全局流（非掩码）**：无空间限制地关注场景令牌，捕获对象间关系与全局光照一致性：
  $$O^{\text{global}} = \text{Attn}(Q^{\text{img}}, \text{RMSNorm}(T^s W_k^{ip}), T^s W_v^{ip}, 0)$$
- **聚合**：通过零初始化的门控参数 $\gamma$ 和尺度因子 $\lambda$ 残差注入：
  $$\hat{H}^{\text{img}} = H^{\text{img}} + \lambda \cdot (O^{\text{global}} + \gamma \cdot O^{\text{local}})$$

### 2.5 训练策略

- **目标函数**：Rectified Flow Matching损失，预测速度 $v = \epsilon - x_0$；
- **t-采样偏移**：使用Logit-Normal采样，但将分布中心偏移至 $m=1.0$（偏重高噪声阶段），使模型优先建立宏观空间布局；
- **边界框掩码损失**：在边界框内部区域增大损失权重（$\alpha=3$），强化前景对象的空间约束；
- **模态解耦丢弃（Modality Dropout）**：随机丢弃全局描述、对象描述等条件模态，支持推理时的Classifier-Free Guidance（CFG）。

### 2.6 推理

用户提供全局场景提示词P和实例条件O即可生成，无需手工制作稠密空间图；也可用LLM将用户指令解析为P和O。

## 6. 主要结论与发现

1. **PoseAdapter在各项指标上全面超越基线**：空间精度（$Acc_{ls}$ 达97.84%/99.40%，在Front/Multi场景上分别超过SceneDesigner约22%和44%）、朝向精度（$Acc_{BOV}$ 达95.44%/93.22%）均显著领先；
2. **双流机制有效解决了隔离与融合的矛盾**：局部流保证精确空间边界、消除属性泄漏；全局流提供关系上下文、提升朝向推断准确性。二者缺一不可；
3. **训练策略具有协同增益**：box mask loss与t-sampling shift各自贡献独立的正向效果，联合使用时增益最大；
4. **轻量化优势显著**：228M可训练参数（仅SceneDesigner的15.3%）+ 零预处理时间，端到端效率大幅优于依赖3D渲染的基线；
5. **多对象场景优势尤为突出**：基线方法在Multi场景中性能大幅下滑（属性泄漏、概念混淆），而PoseAdapter保持了稳定的高质量输出；
6. **背视（Back）场景更具挑战性**：由于背视训练数据有限，所有方法的朝向指标均低于前视场景，但PoseAdapter仍然领先。

## 7. 优点

1. **轻量高效**：以2D框+3D欧拉角的极简条件替代稠密3D图，零预处理延迟，参数量少；
2. **设计针对性强**：精准解决了"掩码隔离导致剪切粘贴"和"无掩码导致属性泄漏"这一核心矛盾，双流架构简洁且有效；
3. **适配现代架构**：模态解耦注入策略（仅注入视觉流）与MM-DiT架构天然兼容，不干扰预训练文本表示；
4. **训练策略有洞见**：t-sampling偏移（侧重高噪声阶段）和box mask loss的设计都体现了对布局引导生成任务特性的深入理解；
5. **数据建设扎实**：构建110K规模的数据集，处理了多源数据的坐标统一、人类验证、语义解耦标注等实际问题；
6. **评估方法有新意**：提出Binary Orientation Verification协议，降低了人工评估的主观偏差，并承认了自动评估的不稳定性；
7. **全局提示词解耦**：训练时使用解耦模态丢弃策略，推理时支持CFG，兼顾条件可控性与灵活性。

## 8. 不足与局限

1. **基线的对比有限**：仅对比了两个SOTA基线，缺少与GLIGEN、InstanceDiffusion等更经典布局控制方法的对比，也缺少在标准benchmark（如COCO-2014布局基准）上的对照实验；
