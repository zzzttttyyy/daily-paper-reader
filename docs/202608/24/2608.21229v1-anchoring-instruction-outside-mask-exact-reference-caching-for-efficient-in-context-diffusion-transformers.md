## 摘要
全模态生成是广泛内容创作与编辑应用的核心。上下文条件化是该范式的重要组成部分，它使扩散Transformer能够在共享注意力序列中处理文本指令和视觉参考。然而，每张参考图像会引入数千个令牌，因此计算量随参考数量快速增长。现有方法通过结构化稀疏注意力来减少计算，但这限制了参考令牌与目标令牌之间的交互。这种结构还使参考的K和V与去噪目标无关，从而可以一次性计算并在多个步骤中复用。然而，它阻止了视觉参考关注文本指令，这显著降低了多参考编辑中的指令遵循和参考保真度。为解决这一冲突，我们重新设计了令牌序列和注意力掩码。我们的越掩码设计使用静态文本锚点将指令连接到参考分支，在无需添加参数的情况下保留精确的K和V复用。然而，这种直接架构转换会降低生成质量。我们通过教师强制的速度蒸馏，随后进行短期的在策略阶段（教师监督学生访问的状态），来恢复丢失的性能。据我们所知，这是在扩散模型中首次使用在策略蒸馏进行架构恢复。在三个图像编辑基准上，我们的方法达到了与全注意力生成相当的质量。在五张参考图像的情况下，它将完整的40步去噪过程加速了3.92倍，而静态文本锚点引入的运行时间开销可忽略不计；在扩展研究中，十张参考时的加速比达到5.47倍。

## Abstract
Omnimodal generation is central to a wide range of content creation and editing applications. In-context conditioning is essential to this paradigm. It allows diffusion transformers to process text instructions and visual references in a shared attention sequence. However, each reference image introduces thousands of tokens. Computation therefore grows rapidly with the number of references. Existing methods reduce computation through structured sparse attention, which limits interactions between reference and target tokens. This structure also makes the reference K and V independent of the denoising target, allowing them to be computed once and reused across steps. However, it blocks visual references from attending to the text instruction. This substantially degrades instruction following and reference fidelity in multi-reference editing. To resolve this conflict, we jointly redesign the token sequence and attention mask. Our beyond-mask design uses static text anchors to connect the instruction to the reference branch. It preserves exact K and V reuse without adding parameters. However, this direct architectural conversion degrades generation quality. We recover the lost performance through teacher-forced velocity distillation, followed by a short on-policy stage in which the teacher supervises student-visited states. To our knowledge, this is the first use of on-policy distillation for architectural recovery in diffusion models. Across three image-editing benchmarks, our method matches full-attention generation quality. With five reference images, it accelerates the complete 40-step denoising process by 3.92x, while static text anchors introduce negligible runtime overhead; the speedup reaches 5.47x at ten references in our scaling study.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想：静态文本锚点（beyond-mask 设计）
- 在原始令牌序列 `[LT, Xt, R]` 之外**扩展**一个静态文本锚点块 `ST`，形成新序列 `[LT, Xt, ST, R]`。
- `ST` 的时间步固定在 t=0，与干净的参考分支对齐；仅在缓存构建阶段存在，构建完成后即被丢弃。
- 注意力图连接规则：
  - R与ST**双向互相可见**（信息通路：指令→参考）；
  - ST和R都**阻断对LT和Xt的注意力**（杜绝目标→参考的依赖路径）；
  - 原始分支保留LT⟷Xt的预训练双向交互，且LT/Xt仍可关注R（但R不回看）。
- 这一设计在注意力图中**新增了一条指令路径 ST→R**，却没有打开目标路径 Xt→R，因此参考K和V既"指令感知"又"与目标无关"，可被精确缓存复用。
- 该构造**不引入任何新参数**：ST复用现有指令嵌入、注意力投影和Transformer权重，且由于NST≪NR，额外的一次性预计算开销仅约为 2NRNST + N²ST 次注意力交互，运行时开销可忽略。

### 2.2 两阶段架构恢复
由于直接架构转换会导致生成质量下降（全注意力权重与新信息流不匹配），论文设计了两个蒸馏阶段：

**阶段一：教师强制速度蒸馏（Teacher-forced Velocity Distillation）**
- 在数据插值点（data-derived interpolants）上，用冻结的全注意力教师向稀疏注意力学生提供速度目标：
  LTF = E[‖vθ(xt, c, t) − vfull(xt, c, t)‖²]
- 其中 xt = (1−t)x0 + tx1 是流匹配插值点，c 包含指令和参考图像。
- 该阶段恢复大部分丢失性能，但由于训练分布与推理轨迹不匹配，会趋于平台期。

**阶段二：在策略细化（On-policy Refinement）**
- 学生用自己的采样器滚动生成轨迹（40步），在访问状态 ẑt 上用 stop-gradient 冻结状态，然后查询教师提供速度目标：
  LOPD = E[‖vθ(ẑt, c, t) − vfull(ẑt, c, t)‖²]
- 关键区别：**教师查询的位置从数据分布切换到学生自身轨迹分布**，直接纠正推理轨迹上的残差错误。
- 据作者所述，这是**首次将on-policy蒸馏用于扩散模型的架构恢复**。

- **两阶段蒸馏训练的定位存疑**：架构转换需要30k+500步训练才能恢复质量，这相对于"无训练/轻量微调"的理想缓存声称仍属较高成本；对于无法访问大训练数据的用户，该方法的实用性受限。且论文未探讨轻量（如仅训练某一层/用LoRA）恢复的可行性。

- **实验基准的覆盖盲区**：测试基准均为图像编辑领域，但论文声称的方法适用于"全模态/omnimodal"扩散Transformer；未见视频、音频或3D生成上的验证，也不见文生图（无参考）场景下该方法的退化影响检测。

- **On-policy阶段的分歧**：附录B明确声明"对该过程不做收敛性声称"，即Stage 2是一种启发式而非有严格收敛保证的优化过程；其成功依赖具体调度和超参数（500步、K=4、学习率5e-6），迁移到其他模型时可能需重新调参。

- **文献引用的时效存疑**：文中大量引用2025年甚至2026年的文献，但arXiv编号为2608.21229v1（2026年8月），这是合理的；然而文中引用"Qwen3"等较早期工作，且没有对比2025年底之后的竞品架构（如FLUX.2后的更新版本），使得比较面略窄。
