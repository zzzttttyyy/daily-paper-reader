## 摘要
身份保持视频生成旨在根据自然语言指令合成视频，同时保持给定主体的视觉身份。近期商业视频生成模型在视觉质量和运动真实性方面取得了显著成果，但在复杂提示词下仍存在身份漂移、指令遵循不完整和视觉细节缺失等问题。由于这些模型通常是闭源黑盒，通过参数优化直接改进往往不可行。为此，我们提出智能体增强与语义修复（AESR），一种用于身份保持视频生成的轻量级增强框架。为在生成前改进提示词构建并缓解上述失败，AESR引入了全局智能体提示增强模块。该模块从官方文档中学习特定模型的提示格式，从人机交互数据中获取以人为中心的视频生成先验，并通过智能体循环将测试域的身份保持生成经验积累到可复用的剧本中。为进一步修复使用增强提示生成的视频中的错误，AESR引入了样本级视觉语义修复模块，该模块使用视觉语言模型（VLM）定位错误视频片段并设计修复指令，将选定帧编辑为显式视觉参考，并引导视频编辑模型修复局部语义或身份相关错误。我们还采用轻量级混合专家（Mixture-of-Experts）选择策略，从不同生成和精炼路径中挑选可靠输出。在ACM MM 2026身份保持视频生成挑战赛的官方评估协议下，我们的系统MIPL\_Video在赛道1中排名第一，验证了AESR在实际身份保持视频生成中的有效性。代码可在https://github.com/oceanflowlab/AESR获取。

## Abstract
Identity-preserving video generation aims to synthesize videos that follow natural-language instructions while maintaining the visual identity of a given subject. Recent commercial video generation models have achieved strong visual quality and motion realism, but they still suffer from identity drift, incomplete instruction following, and missing visual details under complex prompts. Since these models are usually closed-source black boxes, directly improving them through parameter optimization is often infeasible. We therefore propose Agentic Enhancement and Semantic Repair (AESR), a lightweight enhancement framework for identity-preserving video generation. To improve prompt construction before generation and mitigate the above failures, AESR introduces a global agentic prompt enhancement module. This module learns model-specific prompting formats from official documentation, acquires human-centered video generation priors from human-interaction data, and accumulates test-domain identity-preserving generation experience into a reusable playbook through an agentic loop. To further repair errors in videos generated with enhanced prompts, AESR introduces a sample-level visual semantic repair module, which uses a VLM to locate erroneous video segments and design repair instructions, edits selected frames into explicit visual references, and guides a video editing model to fix local semantic or identity-related errors. We also adopt a lightweight Mixture-of-Experts selection strategy to choose reliable outputs from different generation and refinement paths. Under the official evaluation protocol of the ACM MM 2026 Identity-Preserving Video Generation Challenge, our system MIPL\_Video ranked first in Track 1, demonstrating the effectiveness of AESR for practical identity-preserving video generation. The code is available at https://github.com/oceanflowlab/AESR.

**核心矛盾：**

- 生成之前的**提示词构建（Prompt Construction）**
- 生成之后的**草稿修复（Draft Repair）**——借助外部编辑模型

论文提出了一种**无需访问模型参数**的轻量级增强路径，为黑盒视频生成模型在身份保持场景下的可靠性提升提供了通用且可复用的解决方案。该工作在 ACM MM 2026 身份保持视频生成挑战赛 Track 1（人脸身份保持视频生成）中排名第一，验证了实际应用价值。

## 2. 论文提出的方法论（AESR）

**整体框架：** AESR（Agentic Enhancement and Semantic Repair）包含两大互补模块 + 一个选择策略，分为两阶段流水线。

### 2.1 全局级智能体提示增强模块（Global-Level Agentic Playbook Enhancement，GPE）

**核心思想：** 将"模型特定的提示偏好"和"测试域经验"转化为可复用的生成知识，存储于不断演化的 **Playbook（剧本）** 中。

**Playbook 的三类知识结构：**

- **策略（Strategies）：** 通用生成原则，如分阶段动作描述、强化身份细节、主体运动与相机运动分离等。
- **模板（Templates）：** 定义提示组件的组织方式，如人类动作、人机交互、目标状态描述的排列顺序。
- **常见失败模式（Failure Modes）：** 记录目标模型的常见错误及补救措施（如对象缺失、身份约束弱、最终状态不明确）。

**Playbook 的双重初始化来源：**

1. **官方提示文档：** 通过 VLM 分析目标视频模型（Seedance 2.0）的官方文档，学习模型偏好的指令组织方式，提取为三类知识。
2. **外部 Playbook（HOI-Edit 数据集）：** 从人类-物体交互（Human-Object Interaction）编辑数据集中学习经验——由于测试集中超过 95% 的样本涉及人类交互（用 GPT-4o 估计），此类先验对增强交互描述非常关键。

**智能体循环（Agentic Loop）：** 包含四步：

1. **生成（Generation）：** 用当前 Playbook 增强输入指令，生成草稿视频。
2. **分析（Analysis）：** 检查草稿视频，识别失败点。
3. **反思（Reflection）：** 将具体失败抽象为可复用经验（如更强的对象约束、更清晰的时序分阶段）。
4. **整合（Consolidation）：** 审核新经验与现有知识，去重后增量写入 Playbook。

通过这一迭代过程，Playbook 从初始化知识逐步适应测试域。

### 2.2 样本级视觉语义修复模块（Sample-Level Visual Semantic Repair，SVR）

**核心思想：** 文本提示无法解决所有问题。对于高度样本特定的错误（身份漂移、元素缺失、相机运动误解），提供**显式视觉参考**比添加更多文本描述更有效。

**工作流程：**

1. **诊断：** 使用视觉语言模型（VLM）比较草稿视频与原始指令，输出结构化诊断——包括错误类型（缺失视觉元素、错误运动末状态、错误运动过程、其他语义不一致）、问题时间段、错误描述和修复建议。
2. **编辑参考帧：** 对于需要视觉引导的错误，从问题片段中选择代表性关键帧，根据修复建议用图像编辑器进行编辑，生成显式视觉目标（"应该出现什么"）。
3. **视频编辑修复：** 将综合修复指令、编辑后的关键帧（对应目标时间段）、原始身份参考图输入 Seedance 2.0 视频编辑模型，对草稿视频进行局部语义修复。

**两种修复方式的适配：**
- 缺失元素/错误末状态 → 用编辑后的关键帧修复
- 过程级错误（如相机移动速度、转换模式）→ 用文本编辑指令修复

### 2.3 轻量级 MoE 选择策略

- 对每个测试样本，用**五种不同方法路径**生成候选视频。
- 评估每个候选视频的综合得分：`Overall Score = Σ wᵢ · Mᵢ`（M 为评估指标集合，w 为权重）。
- 选择综合得分最高的视频作为最终提交结果。
- 评估指标包括：StoryScore、GMEScore（文本对齐）、ArcScore/CurScore（身份一致性）、Motion Smoothness/Imaging Quality（视频质量）。

### 2.4 实现细节

- **主模型：** Seedance 2.0（闭源视频生成与编辑模型）。
- **身份图预处理：** 将身份图像转换为**铅笔风格身份代理（pencil-style identity proxies）**，保留面部结构信息，同时降低背景颜色、光照等无关因素的影响，支持稳定的批量 API 调用。该格式在 Stage I 生成和 Stage II 修复中一致使用。
- **视频时长：** 所有样本生成 14 秒视频——由于提示通常包含多种视觉元素和运动事件，较长时长给予模型更多时间维度覆盖所需内容。

## 6. 主要结论与发现

1. **AESR 框架有效：** 结合全局提示增强 + 样本级视觉修复 + MoE 选择，在 ACM MM 2026 IPVG 挑战赛 Track 1 中取得第一名（最终得分 2.5），与 USTC-CMI 并列，优于 xuanyuan_fuxi（3.0）。

2. **全局提示增强（GPE）优于单纯官方文档提示：**
   - 仅用官方文档的 Playbook 在身份一致性指标（CurScore 0.6253、ArcScore 0.5868）上表现最佳。
   - 加入测试域经验（+GPE）后，StoryScore 和 GMEScore 显著提升（Story 0.8965→0.8972，GME 0.6563→0.6688），证明测试域经验帮助复杂指令遵循。

3. **视觉语义修复（SVR）与全局增强互补：**
   - 文本仅修复（text-only repair）改善 Imaging Quality（0.6961）；完整 SVR 获得最佳文本对齐分数（StoryScore 0.8994，GMEScore 0.6776）。
   - 定性结果显示 SVR 成功修复了如"目光从目录转向销售员""相机推进聚焦"等局部语义错误。

4. **人类评估与自动指标存在差异：** 图 3 中，视觉上相似的身份保持结果，ArcScore/CurScore 可能有明显波动。因此**人工评分在多指标联合评估中不可或缺**。

6. **铅笔风格身份代理有效：** 简化了身份表征，减少无关外观因素干扰，支持稳定的批量 API 调用。

## 7. 优点

1. **无需参数优化的黑盒兼容性：** 完全在接口层面操作，不依赖模型内部结构，适用于所有闭源商业视频生成 API。这是对当前主流闭源模型生态的高度适配方案。

2. **知识复用的自动化：** Playbook 从"模型文档 + 外部数据集 + 测试反馈"三个来源自动积累知识，将个体样本的失败经验抽象为可迁移的通用策略，避免了对每个样本重复人工调提示。

3. **全局与局部、文本与视觉的双重互补：**
   - 全局提示增强解决"通用模式"问题；样本级视觉修复解决"局部特例"问题。
   - 文本修复与视觉参考修复针对不同错误类型（过程性 vs. 元素性）分别设计，精准匹配。

4. **从知识到决策的完整闭环：** 生成→分析→反思→整合→再生成，形成可自演化的智能体循环。

5. **工程细节务实：** 铅笔风格身份代理、14 秒长视频生成、MoE 多路径选择等设计体现了对实际挑战赛场景的深刻理解。

6. **评估框架严谨：** 指出 CLIPScore 的 77-token 截断问题并改用 StoryScore，展示了专业的方法论判断力。

## 8. 不足与局限

1. **单一基底模型验证：** 所有实验仅基于 Seedance 2.0，AESR 的通用性（对其他闭源模型如 Vidu、Hailuo、Kling 等）未验证。不同模型的提示偏好差异大，Playbook 初始化机制是否稳定有效仍需更多模型测试。

2. **评估样本量有限：** 组件消融仅基于 50 个视频（测试集的 25%），部分指标提升幅度较小（如 GME 0.6563→0.6688，+0.0125），在更大数据集上是否保持显著难以判断。

3. **自动评估指标不稳定性：** 论文承认 ArcScore/CurScore 在视觉上身份保持良好时仍可能大幅波动（如相似身份的图 3 中分数从 0.338→0.318），这限制了自动指标的可靠性；但论文未提出解决该问题的具体方案。

4. **成本与效率问题未探讨：** 基于多个 VLM/编辑模型/视频生成 API 的多路径管道（5 种方法生成候选 + 修复）可能带来较高的 API 调用成本和时间开销。论文未提供任何关于推理延迟、经济成本的分析。

5. **MoE 权重设定主观性：** Overall Score 中权重 wᵢ 的选择依据未充分说明，存在人工调参的偏差风险。

6. **Playbook 可扩展性存疑：** Playbook 的"反思-整合"机制严重依赖 VLM 的分析质量，且初始知识来自单一外部数据集（HOI-Edit）和单一模型文档，在其他领域（非人类交互场景）的知识覆盖可能不足。

7. **身份保持评估维度单一：** 虽然术语是"identity-preserving"，但论文主要针对**人脸身份**（Track 1 焦点），对于更广泛的主体身份保持（如物体、动物、多主体交互）未做讨论。

8. **局限性声明缺失：** 实验证明了在 ACM MM 26 挑战赛框架下的有效性，但缺乏对失败案例的系统性分析（比如修复失败的情况、Playbook 引入错误经验的场景）。
