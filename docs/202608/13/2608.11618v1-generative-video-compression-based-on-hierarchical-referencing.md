## 摘要
基于扩散的生成式视频压缩已成为一种有前景的范式，用于提升感知质量，其中潜在帧需要被高效编码，同时作为去噪条件。然而，现有方法在潜在编码过程中既未仔细设计参考和质量结构，也未考虑帧级质量变化对去噪过程的影响，这限制了编码效率并加剧了生成重建过程中的伪影传播。本文提出GVCHR，一种基于分层引用的生成式视频压缩方法。其关键思想是层次化地组织潜在帧，其中选定的高质量参考既有利于潜在编码，也有利于生成重建。在潜在编码中，GVCHR将分层参考结构与分层质量结构耦合，为更频繁被复用为参考的低层帧分配更多比特。基于此设计，我们引入分层时域上下文挖掘，以利用互补的短期和长期时域上下文进行有效的潜在编码。在生成重建中，编码端的分层结构被纳入分层注意力适配器，该适配器附加到视频扩散Transformer上。该适配器使用分层注意力来限制每个潜在帧仅关注同层或更低层的参考，从而减少去噪过程中的伪影传播。实验在多个基准上验证了GVCHR。与先前最先进的方法相比，GVCHR在LPIPS和DISTS指标上分别实现了50.5%和54.0%的BD-rate增益，同时提供了明显更好的视觉质量。

## Abstract
Diffusion-based generative video compression has emerged as a promising paradigm to improve perceptual quality, where latent frames are required to be encoded efficiently while serving as denoising conditions. However, existing methods neither carefully design reference and quality structures during latent coding nor account for the impact of frame-level quality variation on denoising procedure, which limits coding efficiency and aggravates artifact propagation during generative reconstruction. In this paper, we propose GVCHR, Generative Video Compression based on Hierarchical Referencing. The key idea is to organize latent frames hierarchically, where the selected high-quality references benefit both latent coding and generative reconstruction. In latent coding, GVCHR couples a hierarchical reference structure with a hierarchical quality structure, assigning more bits to lower-layer frames that are reused more frequently as references. Built on this design, we introduce Hierarchical Temporal Context Mining to exploits complementary short- and long-term temporal context for effective latent coding. In generative reconstruction, the coding-side hierarchy is incorporated into a Hierarchical Attentive Adapter which is attached to a video diffusion transformer. This adapter uses hierarchical attention to restrict each latent frame to attend only to the same- or lower-layer references, thereby reducing artifact propagation during denoising. Experiments validate GVCHR on multiple benchmarks. Compared with the previous state-of-the-art method, GVCHR achieves 50.5% and 54.0% BD-rate gains in terms of LPIPS and DISTS, respectively, while also delivering clearly improved visual quality.

### 1. 核心问题与整体含义

随着视频流量占据互联网主导地位，高效视频压缩对于节省存储和传输成本至关重要。传统编码器和多数神经视频压缩方法主要面向保真度优化（如PSNR、MSE），但这类目标与人眼感知存在偏差，在低比特率下容易产生模糊和伪影。

近年来，扩散模型因其出色的图像/视频合成能力，为生成式视频压缩（GVC）带来突破。此类方法的典型流程为：先用3D VAE将视频映射到潜在空间，再用学习型编码器压缩潜在帧，最后以解码后的潜在帧为条件，驱动扩散模型去噪重建高质量视频。

**现有方法的不足**：尽管扩散模型提升了视觉质量，现有扩散式GVC方法仍有两个核心缺点：
- 在**潜在编码**阶段，未充分设计参考帧结构和质量分配策略——简单逐帧引用导致重要参考帧的编码质量无法得到保证，编码效率受限；
- 在**生成重建**阶段，采用全帧注意力使低质量帧的失真信息可无约束地扩散到其他帧，加剧伪影传播。

**核心含义**：本文提出GVCHR，核心思想是**层次化组织潜在帧**，形成少量高质量、高可靠性的参考帧，同时支撑高效编码与高质量生成重建，实现编码端与重建端的统一层次化设计。

### 2. 方法论

#### （1）整体框架
GVCHR 由两个端组成：
- **层次化潜在编码**：基于条件编码框架（DCVC-RT）构建，引入分层参考与质量结构；
- **扩散生成重建**：将解码潜在帧注入视频扩散Transformer（视频DiT），通过分层注意力适配器（HA-Adapter）引导去噪。

#### （2）层次化潜在编码
- 输入视频先经**关键帧采样**（灰度化中间帧），保留颜色信息于关键帧中，减少传输比特数；
- 使用3D VAE编码器得到潜在帧序列 {x_t}，再送入潜在编码器压缩；
- 潜在帧在结构上被划分为**多个层级**：
  - **低层帧**：复用次数多、分配更多比特、编码质量高，可作参考；
  - **高层帧**：编码更紧凑、不能为低层帧提供参考。
- 分层质量结构通过RD训练损失中的权重 w_t 实现：层越低权重越高，编码质量越好。默认采用三层结构，潜在mini-GOP=4，权重模式为 [w_t, ..., w_{t+3}] = [0.5, 0.9, 0.5, 1.2]，对应层ID为 {2, 1, 2, 0}。

#### （3）层次化时域上下文挖掘（HTCM）
在编码端基于层次结构提取两类互补上下文：
- **短期参考**：取同一层或更低层中最近解码帧的特征 c_t^S := f_s，保留局部细节；
- **长期参考**：用门控槽注意力（GSA）以循环方式将此前所有最低层（第0层）帧的特征更新至固定大小的长期记忆库 m_l，捕获全局语义；
- 最终通过跨注意力将长期上下文与短期上下文对齐融合，经上下文精炼网络生成条件特征 c_t 和 c_t^e，用于条件编码/解码和熵参数估计。

#### （4）分层注意力适配器（HA-Adapter）
- 解码后的潜在帧 {x̂_t} 和特征 {f̂_t} 经控制信号嵌入器patch化得到帧级token {x̂'_t}；
- 在HAT（Hierarchical Attentive Transformer）块中，用**分块注意力掩码** M 控制帧间注意力：
  - M_{i,j} = 0 当 L_i ≥ L_j（允许高/同层帧关注低层帧）；
  - M_{i,j} = −∞ 当 L_i < L_j（禁止低层帧关注高层帧）；
- 从而限制每帧仅关注同层或更低层的高质量参考，**防止低质量高层帧的编码伪影在去噪过程中污染低层的关键参考帧**；同时，块状掩码可借助块注意力机制加速计算。

#### （5）多阶段训练策略
六阶段渐进式训练：

| 阶段 | 训练对象 | 损失 |
|---|---|---|
| 1–3 | 仅潜在编码器，帧数从5增至33 | L_Codec（潜在MSE损失 + 层次权重） |
| 4 | 编码器 + HA-Adapter | L_Codec + L_CFM（条件流匹配损失） |
| 5 | 编码器 + HA-Adapter（多质量点） | 0.1L_Codec + 0.1L_CFM + L_Rec + 0.1L_LPIPS |
| 6 | 高分辨率微调，去掉L_CFM | 0.025L_Codec + L_Rec + 0.1L_LPIPS |

RD训练损失为 L_RD = R + λD，λ在[160, 3072]间取5档，分别训练对应5个质量等级的模型；推理时配合量化参数（QP）偏移控制码率。

### 6. 主要结论与发现

- **性能优势**：在LPIPS和DISTS两个关键感知指标上，相比最新方法GNVC-VD，GVCHR分别实现**50.5%和54.0%的BD-rate增益**（GOP 32设置）；

### 7. 优点

- **体系化创新**：首次在扩散式GVC中实现编码端与重建端**统一的层次化设计**，编码端参考/质量结构直接延伸到重建端去噪流程，逻辑闭环清晰。
