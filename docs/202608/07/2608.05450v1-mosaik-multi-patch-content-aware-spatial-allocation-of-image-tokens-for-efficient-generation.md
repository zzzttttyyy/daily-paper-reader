## 摘要
像素空间扩散模型通过直接在图像空间生成，避免了潜在扩散模型的重建上限。然而，由于标记数量显著增加，加上自注意力的二次复杂度，导致生成成本高昂。现有的几种效率方法通过在选定的去噪步骤中使用更大的补丁来降低这一成本，从而用更少的标记表示图像。然而，每个步骤仍在整个图像上统一使用单一补丁大小，忽略了不同区域在粗糙化时会产生不同的保真度损失。我们提出了MOSAIK，一种损伤引导框架，它在不同区域和去噪步骤之间动态调整补丁大小。MOSAIK将PixelDiT主干网络适配为可生成任意异构补丁布局，并通过一个轻量级预测器利用中间去噪特征来估计每个区域因粗糙化而造成的保真度损失。在给定的标记预算下，该损伤引导布局预测器为敏感区域分配精细补丁，在其他区域分配粗糙补丁。值得注意的是，在减少70%的FLOPs和83%的标记数量的同时，MOSAIK在GenEval上达到了与全计算量PixelDiT相当的性能，其DPG-Bench分数仅下降1.0个点。与包括时间补丁调度和特征缓存在内的多种效率方法相比，我们的方法在中等预算下展现出极具竞争力的性能，并在高度受限的计算条件下持续优于这些基线。

## Abstract
Pixel-space diffusion models avoid the reconstruction ceiling of latent diffusion models by generating directly in image space. However, their substantially higher token count makes generation expensive due to the quadratic complexity of self-attention. Several existing efficiency methods reduce this cost by using larger patches at selected denoising steps, thereby representing the image with fewer tokens. Yet, each step still uses a single patch size uniformly across the entire image, overlooking that different regions suffer different fidelity losses when coarsened. We introduce MOSAIK, a damage-guided framework that varies patch size across regions and denoising steps. MOSAIK adapts the PixelDiT backbone to generate arbitrary heterogeneous patch layouts, and a lightweight predictor uses intermediate denoising features to estimate the fidelity loss caused by coarsening each region. Given a token budget, our damage-guided layout predictor assigns fine patches to sensitive regions and coarse patches elsewhere. Remarkably, while reducing FLOPs by 70% and token count by 83%, MOSAIK matches the full-compute PixelDiT on GenEval and its DPG-Bench score drops by only 1.0 point. Compared to diverse efficiency paradigms, including temporal patch scheduling and feature caching, our approach delivers highly competitive performance at moderate budgets and consistently outperforms these baselines in highly constrained compute regimes.

## 1. 论文的核心问题与整体含义

- **背景**：像素空间扩散模型（PDM）直接在图像像素空间上生成图像，避免了潜在扩散模型（LDM）中 VAE 压缩导致的**重建上限**（高频率细节无法恢复）问题。然而，像素空间生成带来了**更高的 token 数量**，而 Transformer 自注意力的计算复杂度与 token 数量呈二次方关系，导致生成成本极高。
- **现有方法的不足**：已有的一些效率优化方法（如 DDiT、PPFlow 等）通过在时间维度上调度 patch 大小（在噪声高的步骤用粗 patch，在噪声低的步骤用细 patch），但**在任意给定时间步内，整个图像仍使用统一 patch 大小**。这种空间上均匀的处理方式忽略了一个关键事实：当 patch 被粗化时，不同图像区域承受的保真度损失（fidelity loss）是不同的——精细纹理、物体边界等区域对粗化高度敏感，而平滑背景区域则几乎不受影响。
- **核心问题**：能否在生成过程中，根据图像内容在各区域之间**动态地、自适应地分配不同大小的 patch**，将计算资源集中在真正需要精细结构的区域，从而在不牺牲视觉质量的前提下显著降低计算成本？

## 2. 论文提出的方法论

### 2.1 核心思想

MOSAIK 的核心思想是**将异构 patch 布局的执行与布局分配策略解耦**，通过一个"损伤引导"的机制实现内容感知的空间 token 分配。其关键洞见是：**粗化（coarsening）导致的生成偏差可以直接作为分配信号**——预测损伤越大的区域，越应分配细 patch。

### 2.2 三阶段训练管道

整个训练过程采用**自蒸馏（self-distillation）**方式，以冻结的 PixelDiT 教师模型（uniform p16）的输出作为保真度参照。

**阶段 1：多 Patch 流畅性（Multi-Patch Fluency）**

- **架构改造**：冻结主干权重，在 DiT 块中注入 LoRA（rank=32）模块；新增 p32 和 p64 的词元化器（tokenizer）；为每个 token 添加可学习的 patch size 嵌入（类似时间嵌入）；引入可学习的 pixel-shuffle 条件上采样器，将粗 token 表示映射回统一 p16 网格，以适配固定的 PiT 像素解码器。
- **训练目标**：通过 L2 自蒸馏损失，让多 patch 生成器在不同均匀 patch 布局下的速度场预测匹配教师模型的 p16 预测：L_self-distill = E[‖v_θ^P(x_t, σ, y) − v_teacher^16(x_t, σ, y)‖²]。

**阶段 2：混合 Patch 适应（Mixed-Patch Adaptation）**

- **位置嵌入**：异构布局下 p16/p32/p64 token 共享同一序列，不能按序列顺序分配 RoPE 位置。MOSAIK 将每个 token 锚定到其 patch 在归一化 p16 坐标系中的**几何中心**，保持了位置信息的一致性。
- **训练策略**：随机采样异构 patch 布局（概率 0.6）与均匀布局（概率 0.4），强制生成器在任意布局下都能可靠执行，匹配教师预测。

**阶段 3：损伤引导布局预测器（Damage-Guided Layout Predictor）**

- **损伤图定义**：计算 uniform p64 生成器预测与 p16 教师预测之间的逐像素平方差，并在 64×64 区域内平均池化，得到每区域的损伤目标：
  d̃_t = AvgPool(‖v_θ^64(x_t, σ, y) − v_teacher^16(x_t, σ, y)‖²)
- **轻量预测器**：鉴于推理时无法承担额外的教师前向传播，训练一个约 1.63M 参数的轻量卷积网络 f_ϕ（含 FiLM 条件调制和自注意力层），从**第 6 个 DiT 块的中间激活**（前一时刻的 h^t−1_6）回归损伤图，损失函数为 Huber loss。
- **推理时的 token 分配算法**：第一步使用均匀 p16 产生初始激活；后续每一步从预测的损伤图出发，所有区域初始化为 p64，由高到低按"损伤/新增 token 数"的优先级执行两次迭代细化（p64→p32 加 3 token，p32→p16 加 12 token），直至满足用户指定的 token 预算。该方法与预算无关，同一模型可在任意推理预算下工作。

## 6. 论文的主要结论与发现

1. **显著的计算压缩**：MOSAIK 在降低 70% FLOPs 和 83% token 数的情况下，GenEval 匹配全计算 PixelDiT（0.74），DPG-Bench 仅下降 1.0 分（83.5→82.5）。
2. **质量稳定性优势**：在 25%～83% 的 token 压缩范围内，GenEval 保持在 0.74 附近、DPG 波动仅 1 分；而所有其他对比方法（步骤截断、缓存、时间调度）都随计算预算收紧而持续降质。
3. **优于时间维度调度**：DDiT 的时间 patch 调度在 27% token 压缩时就已落后 MOSAIK 0.05 GenEval；在极限压缩下（70% FLOPs 减少），DDiT 降至 0.64，而 MOSAIK 保持 0.74。空间分配能实现 DDiT 无法做到的按需区域分配（背景 0.8×，主体边界 2.17×）。
4. **与特征缓存互补**：MOSAIK 的空间压缩与 TeaCache/TaylorSeer 的时间缓存正交，组合后在 80% FLOPs 减少下仍保持 GenEval 0.73、DPG 82.2，有效弥补了缓存方法在极端压缩下的性能坍塌。
5. **损伤引导的有效性**：在相同 generator、预算和种子下，损伤驱动布局显著优于随机布局，且差距随预算收紧而扩大。
6. **像素空间更适合自适应压缩**：实验表明，对 VAE 潜在表示进行粗化的感知损伤是像素空间的 1.68×～1.91×，因为 VAE 编码器已"透支"了空间冗余，像素空间中保留的冗余更多，为动态分配提供了空间余量。

## 7. 优点

1. **问题定义明确且有价值**：指出统一 patch 大小忽略了空间异质性这一关键盲区，是效率方法的自然延伸。
2. **三阶段解耦训练设计精妙**：将"多 patch 执行能力"与"分配策略"分离，布局预测器离线训练，推理时无需端到端联合优化，且训练与预算无关（同一模型可适配任意推理预算）。
3. **损伤直接作为分配信号**：不是从生成目标中间接地学习分配行为，而是显式地预测"粗化损伤"，可解释性强，且通过 Spearman 秩相关验证了预测质量决定分配行为（而不是绝对回归误差）。
4. **工程实现完整**：解决了异构布局中的位置嵌入问题、粗 token 与固定 p16 解码器的衔接问题；测量了端到端延迟（而非仅 FLOPs），并指出固定 PiT 解码器是压缩的硬底（21% 固定开销）。
5. **公平考量较好**：FLOPs 按整个 denoiser 而非仅动态模块计算；与 DDiT 比较时固定 seeds、步数、引导值，并披露了复现配置。

## 8. 不足与局限

1. **并非免训练方法**：尽管元数据中提到"免训练的补丁分配策略"，但实际方法需要训练 LoRA 适配器（阶段 1、2）和损伤预测器（阶段 3），需要额外的数据收集与训练成本；只有训练完成后推理阶段的分配本身不依赖额外训练。
2. **架构依赖较强**：方法基于 PixelDiT 的特定架构（patch-level DiT + pixel-level PiT 解码器），迁移到其他像素空间模型（如 DiP、DeCo、HyperDiT）或视频生成场景需要重新适配和训练。
3. **固定开销限制压缩上限**：PiT 像素解码器和文本流不随 patch 大小缩放（约占 p16 全量的 21%），导致纯空间方法最多只能实现约 75% 的 FLOPs 减少，进一步压缩需要与时间维度方法结合。
4. **评测指标覆盖不足**：缺少 FID 等生成质量分布级指标、缺少用户研究；GenEval/DPG 主要衡量提示对齐，对纹理细节的反映有限（作者补充了 DISTS/LPIPS 对照，但这两者是对比全量 PixelDiT 输出，非地面真实图像）。
5. **复现偏差风险**：DDiT 和 TaylorSeer 均为作者自行复现，DDiT 官方实现未公开，复现的质量和参数校准可能影响对比公平性；不过论文中已给出 DDiT 的敏感性分析，以缩小该风险。
6. **隐私与泛化数据限制**：训练主要基于 BLIP3o-60k 等固定数据池，跨领域泛化能力未充分验证；布局预测器基于 4,000 提示词的轨迹收集，可能对长尾提示词覆盖不足。
7. **首次去噪步骤必须全计算**：推理时第一步需使用 uniform p16 以产生初始激活，在极短生成的场景下首步开销占比会增大。
