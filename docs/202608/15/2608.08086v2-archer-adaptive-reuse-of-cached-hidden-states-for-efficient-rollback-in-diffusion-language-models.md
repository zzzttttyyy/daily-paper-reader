## 摘要
扩散语言模型（DLM）迭代地细化序列，使得早期预测可以随着上下文演变而被修正。这种回滚能力使它们区别于不可逆的自回归生成，但也导致推理成本高昂。每次去噪更新都会改变全局上下文，迫使提示和响应状态都被重新计算，即使只有响应标记是可修改的。键值（KV）缓存可以降低这一成本，但传统缓存假设历史状态不可变，因而难以与回滚兼容。在本文中，我们介绍了用于高效回滚的缓存隐藏状态自适应复用方法（Archer），这是一种针对可回滚DLM的免训练KV缓存方法。Archer不对称地将可变的响应与当前假设保持同步，同时在受限状态邻域内复用提示K/V。尽管在双向注意力下提示表示也会变化，但其标记身份保持不变；因此，有界复用分摊了重复的提示计算，而无需缓存可变的响应状态。它还延迟了暂定令牌的反馈，减少了对瞬时高置信度错误的过早强化，并为回滚提供更多纠正机会。我们的分析将提示复用刻画为一种与可逆性对齐的缓存边界，界定了其状态相关的近似误差，并给出了保持全刷新决策的解码器边际条件。现有的DLM加速常常以质量换取速度。Archer改变了这一权衡前沿，在主测试套件上实现了33.63%的最佳平均性能以及2.57倍的平均加速。在评估的设置中，它将Pass@1提升了最多3.05个百分点，并达到最高2.95倍的加速。受控分析将质量提升与延迟的提示反馈联系起来，并验证了状态感知的刷新。我们的代码可在 https://github.com/Hxnng/Archer 获取。

## Abstract
Diffusion language models (DLMs) iteratively refine a sequence, allowing earlier predictions to be revised as context evolves. This rollback capability distinguishes them from irreversible autoregressive generation, but makes inference costly. Every denoising update alters the global context, forcing both prompt and response states to be recomputed even though only response tokens are revisable. Key-value (KV) caching could reduce this cost, yet conventional caching assumes immutable historical states and is therefore difficult to reconcile with rollback. In this paper, we introduce Adaptive Reuse of Cached Hidden States for Efficient Rollback (Archer), a training-free KV caching method for rollback-capable DLMs. Archer asymmetrically keeps the mutable response synchronized with the current hypothesis while reusing prompt K/V within a bounded state neighborhood. Although prompt representations also change under bidirectional attention, their token identities remain fixed; bounded reuse therefore amortizes repeated prompt computation without caching mutable response states. It also delays feedback from tentative tokens, reducing premature reinforcement of transient high-confidence errors and giving rollback more opportunity to correct them. Our analysis characterizes prompt reuse as a reversibility-aligned cache boundary, bounds its state-dependent approximation error, and gives a decoder-margin condition for preserving full-refresh decisions. Existing DLM acceleration often trades quality for speed. Archer shifts this frontier, attaining the best mean performance of 33.63% together with a 2.57x mean speedup on the main suite. Across evaluated settings, it improves Pass@1 by up to 3.05 points and reaches up to 2.95x speedup. Controlled analyses connect the quality gain to delayed prompt feedback and validate state-aware refresh. Our code is available at https://github.com/Hxnng/Archer.

## 1. 论文的核心问题与整体含义

扩散语言模型（Diffusion Language Models, DLMs）通过迭代双向去噪生成序列，与不可逆的自回归生成相比，其核心优势在于**回滚（rollback）能力**：早期预测可以在后续上下文变化时被重新审视和修正。然而，这种灵活性带来了高昂的推理成本：

- 每次去噪更新都会改动全局上下文，导致即使是只允许修改 response 标记的模型，也必须同时重新计算 prompt 和 response 的隐藏状态。
- 传统 KV 缓存假设历史状态不可变，因而**无法直接套用于具备回滚能力的 DLM**——生成状态随时可能失效，缓存反而可能强化临时错误。
- 现有方法割裂地处理“回滚质量”或“DLM 效率”：回滚解码器（如 Saber、WINO、ReMeDi）虽然能提升生成质量，但每步都做全序列前向；DLM 加速器（如 Fast-dLLM、dKV-Cache、dLLM-Cache）虽然压缩了计算，但未考虑 token 级回滚带来的缓存失效问题。

**Archer 的整体含义**：它打破了“缓存”与“回滚”互斥的假设，主张缓存边界应沿“可修订性”的语义来确定——即缓存不变的部分（prompt），重算可变的部分（response）。这不仅在效率上分摊了 prompt 的重复计算，还通过**有界延迟 prompt 反馈**改善了回滚动力学，在质量与速度之间实现了正向迁移。

## 2. 方法论：Archer

### 2.1 核心思想

Archer 是一个**免训练（training-free）的 KV 缓存控制器**，与底层 DLM 和回滚策略完全解耦。其核心设计遵循一个原则：

> 生成状态（response）是回滚作用的对象，必须保持完全可修订；prompt 的 token 身份固定，因此其 K/V 可在有界邻域内安全复用。

Archer 采用**不对称复用**：

- **Response 侧**：每次更新都完整重新计算所有生成嵌入、推理、logits，保证回滚空间不被截断。
- **Prompt 侧**：在满足条件时直接复用上一次“锚定（anchor）”时保存的 prompt K/V，避免对固定 prompt 的重复前向计算。

### 2.2 关键技术与公式

**标记与设定**：
- \( p \)：固定 prompt，\( g_t \)：当前 response，\( D \)：回滚解码器。
- \( C_p(g) \)：response 为 \( g \) 时前向得到的 prompt K/V。
- \( \Phi_\theta(g; C) \)：使用 prompt 缓存 \( C \) 对 response \( g \) 执行生成前向。

**Eager 解码**（基线）：
\[
z^\star_t = \Phi_\theta(g_t; C_p(g_t)), \quad g_{t+1} = D(g_t, z^\star_t)
\]

**Archer 解码**（缓存时）：
\[
\hat{z}_t = \Phi_\theta(g_t; C_p(g_r))
\]
其中 \( g_r \) 是最近一次刷新时锚定的 response。

**状态锚定刷新（State-Anchored Refresh）**：Archer 用锚定响应与当前响应的 Hamming 距离作为缓存有效性度量：
\[
D_t = d_H(g_t, g_r) = \sum_{i=1}^{G} \mathbb{I}[g_{t,i} \neq g_{r,i}]
\]
当 \( D_t \ge K \)（半径阈值）时，执行全量前向并刷新 prompt 缓存，同时令 \( g_r \gets g_t \)；否则沿用缓存：
\[
\tilde{z}_t =
\begin{cases}
\Phi_\theta(g_t; C_p(g_t)), & D_t \ge K \\
\Phi_\theta(g_t; C_p(g_r)), & D_t < K
\end{cases}, \quad g_{t+1} = D(g_t, \tilde{z}_t)
\]

**算法流程（Algorithm 1 的要点）**：
1. 初始化 response \( g \) 和锚点 \( g_r \)，先做一次 FULLFORWARD 获得初始 prompt 缓存与 logits。
2. 循环直到终止：由解码器 \( D \) 更新 \( g \)。
3. 若未终止且 \( d_H(g, g_r) \ge K \)，则刷新（FULLFORWARD）；否则仅用缓存前向（CACHEDFORWARD）。
4. 最终返回生成的 response。

### 2.3 理论刻画

- **缓存边界命题（Proposition 1）**：在任意 response 修订下，精确的 generation-state 复用要求重算其完整双向依赖闭包；Archer 不缓存任何 generation state，因此完整保留原始解码器的替换与重掩码能力。
- **近似误差界**：在 Lipschitz 假设下（问题 Eq. (10)），缓存步骤的 logit 误差满足：
  \[
  \|z^\star_t - \hat{z}_t\|_\infty \le \Gamma \sqrt{D_t} < \Gamma \sqrt{K}
  \]
  说明误差受**状态距离**（而非墙上时间）控制。
- **决策保持条件**：给定解码器边际 \( m_D(g, z) \)（最小扰动使动作改变），当 \( \Gamma \sqrt{D_t} < m_D(g_t, z^\star_t) \) 时，Archer 与全刷新选择相同的下一个动作。
- **反馈控制视角**：prompt 复用暂时抑制了“response → prompt → response”的交叉反馈路径 \( \partial_C \Phi_\theta \partial_g C_p \)，而不改变 response 内部的作用路径，从而提供短期正则化，配合周期刷新维持长期一致性。

## 6. 主要结论与发现

1. **打破质量-速度的权衡前沿**：Archer 在 5 个质量分数和 3 个加速比的平均上取得最佳平均性能 33.63% 和 2.57× 平均加速；单 benchmark 加速最高达 2.95×（LiveCodeBench）。
2. **跨 backbone 稳定迁移**：在 6 组模型-基准组合上均获得 1.36–1.78× 的加速，并在 5 组中提升 Pass@1；其中 DiffuCoder-HumanEval 达到 +3.05 个百分点的最大提升。
3. **延迟 prompt 反馈带来质量增益**：在完全相同状态和回滚规则的匹配实验中，Cached 分支在 MBPP Base/ET 上均比 Fresh 高 1.17 个百分点；两分支 99.53% 的 token 都在约相同步数内被修订，说明差异源于反馈时序而非回滚的削弱。
4. **状态距离优于缓存年龄**：以锚点距离 \( D_t \) 为信号的缓存刷新机制在决策不一致的校准上单调且信息量显著高于单纯按步数计算年龄的信号（partial Spearman 0.145 vs 0.040）。
5. **回滚未因缓存而冻结**：Archer 的修订比例与 Saber 相当（如 MBPP 上 30.03% vs 29.18%），加速来自单步工作的降低而非跳过纠错。
6. **缓存复用收益随 prompt 增长而扩大**：在 G=256 时，从 P=128 到 P=2048，单步缓存加速从 1.30× 提至 4.62×。

## 7. 优点

- **概念清晰**：将“缓存边界”与“可修订语义”对齐，从理论上说明了为什么 prompt 侧缓存是回滚兼容的天然边界，而 generation 侧缓存则难有通用保证。
- **免训练与即插即用**：不修改底层 DLM 或回滚策略，可以直接套用于 LLaDA、Dream、DiffuCoder 等多种 backbone，也不引入特定任务的先验。
- **有界延迟反馈的机制洞见**：将 prompt 缓存提升为一种**可控的反馈控制手段**——既带来加速又改善纠正动力学，而不是简单的近似误差源。

- **工程视角周到**：附录给出长度扩展、NFE 差异、案例分析和失败边界案例，体现了对系统性能与失效模式的双重关注。

## 8. 不足与局限

- **缓存边界保守**：作者明确承认 Archer 只复用了 prompt 状态，response 侧没有做任何复用，因此并未穷尽所有计算节省空间。当未来模型引入稀疏注意力或有效性证书机制时，generation 侧缓存可能是进一步的优化方向。
- **实验覆盖有限**：主实验聚焦代码生成，跨域泛化仅覆盖数学、金融、生物医学三个任务，欠缺开放域文本生成等更通用的场景验证。
- **跨 backbone 的 Perf 提升不均**：在 HumanEval-Base 上 LLaDA 的 Pass@1 反而下降 1.22 点，说明延迟反馈并非总是有益的；最优刷新半径依赖具体任务与模型，缺少自动调节机制。
- **理论假设的适用性**：Lipschitz 常数和嵌入直径（B）对于大规模预训练模型通常不可数值验证，论文也承认其误差界是结构性的而非数值型保证。
- **资源信息缺失**：未报告 GPU 型号、数量、整体耗电等算力信息，不利于其他研究者复现对比或预估成本。
- **对长上下文与流式交互的验证不足**：实验最大生成长度与块长度均为 256，尚不能确认在更长输出或对抗性且真实场景的交互式生成中，Archer 的回滚效率和延迟反馈效应是否依然成立。
- **未与 Reversible Diffusion Decoding 等 block 级缓存方法直接对比**：虽然论文指出其不关注双向生成区域内的细粒度修订，但缺少实证对比仍然是一个交互层面上的不确定性。
