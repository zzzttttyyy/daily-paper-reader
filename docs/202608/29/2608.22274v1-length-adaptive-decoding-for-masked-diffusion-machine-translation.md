## 摘要
机器翻译考验掩码扩散语言模型（dLLMs），因为每个源词元都必须被忠实地呈现，而固定画布解码必须在去噪之前选择目标长度。现有的掩码扩散解码工作主要研究词元去掩码顺序，尽管长度决策直接影响覆盖率和冗余度，但对此研究不足。我们引入了Entropy-Valley（EV），一种无需训练的长度选择器，通过全掩码前向传递的平均预测熵对候选目标画布进行评分，并选择主干网络最有准备填充的画布。相对于使用训练语料长度统计的基线，EV在En→Zh、Zh→En和En→De上分别恢复了参考目标长度所得COMET-22增益的64.9%、65.3%和33.0%。我们的诊断表明，有利于去噪的长度不必与参考长度匹配。三位翻译专家的评估支持了En↔Zh的充分性增益，其中Zh→En的证据更强。与在同一微调数据上训练的LLaMA-3-8B自回归（AR）模型相比，EV系统在En→Zh上持平，在Zh→En上领先；一个oracle长度诊断进一步表明，在这种掩码扩散MT设置中，决定首先揭示哪些词元不如如何提供目标长度重要。

## Abstract
Machine translation tests masked diffusion language models (dLLMs) because every source token must be rendered faithfully, while fixed canvas decoding must choose target length before denoising. Existing masked diffusion decoding work mainly studies token unmasking order, leaving this length decision under-explored despite its direct effect on coverage and redundancy. We introduce Entropy-Valley (EV), a training-free length selector that scores candidate target canvases by mean predictive entropy from all-mask forward passes and selects the canvas the backbone is most prepared to fill. Relative to a baseline using training corpus length statistics, EV recovers 64.9%, 65.3%, and 33.0% of the COMET-22 gain from reference target lengths on En$\to$Zh, Zh$\to$En, and En$\to$De. Our diagnostics show that denoising-friendly lengths need not match reference lengths. Evaluation by three translation experts supports the En$\leftrightarrow$Zh adequacy gains, with stronger evidence on Zh$\to$En. Compared with a LLaMA-3-8B autoregressive (AR) model trained on the same fine-tuning data, the EV system ties on En$\to$Zh and leads on Zh$\to$En; an oracle-length diagnostic further shows that, in this masked diffusion MT setting, deciding which tokens to reveal first matters less than how the target length is supplied.

## 论文总结：Length-Adaptive Decoding for Masked Diffusion Machine Translation

### 1. 核心问题与研究动机

- **研究背景**：掩码扩散语言模型（Masked Diffusion Language Models, dLLMs）在开放式生成与推理任务上已接近自回归（AR）大语言模型，但其在机器翻译（MT）任务上面临独特挑战：MT 要求每个源词元都被忠实呈现，而固定画布（fixed-canvas）解码要求先指定目标长度再去噪。
- **核心问题**：现有掩码扩散解码研究多聚焦于“先揭示哪些掩码位置”（unmasking order），却忽视了目标长度选择这一直接影响翻译覆盖率与冗余度的关键决策。若画布过短会遗漏动词、占位符等源信息；若过长则可能产生重复、幻觉或稀释语义。
- **研究缺口**：借用非自回归MT的长度预测机制并不完全适用，因为存在训练目标不匹配问题；使用单一语料级源-目标长度比例过于粗糙，无法适应不同句子的压缩/扩张需求。作者希望在不额外训练、不使用参考长度的前提下，让预训练的掩码扩散模型在推理时自行选择合适的目标画布长度。

### 2. 方法论：Entropy-Valley（EV）

- **核心思想**：利用模型自身的“全掩码预测熵”作为长度选择信号。对每个候选长度进行一次全掩码前向传播，计算各槽位预测熵的均值，选择使熵最低（模型“最有准备填充”或“最容易去噪”）的画布长度。**注意其目标是找到一个利于去噪的长度，而非拟合人类参考长度**。
- **具体流程（四步）**：
  1. **构建候选画布长度**：从固定的源-目标长度比集合 $R$ 出发，将每个比值映射为整数画布长度并去重：$C(x)=\{\max\{1,\lfloor r|x|\rfloor\}+1: r\in R\}$（$|x|$为源句词元数，$+1$预留给EOS槽位）。
  2. **全掩码熵探测**：对每个候选长度 $L$，构造输入 $[\text{prompt}(x)]\|[\text{MASK}]^L$，一次前向传播获取各槽位预测分布，计算平均预测熵 $\bar{H}(L)=\frac{1}{L-1}\sum_{i=1}^{L-1} H(p_\theta(y_i|x,[\text{MASK}]^L))$（排除EOS槽）。
  3. **熵谷选择**：选出熵最低的候选长度 $L^\star = \arg\min_{L\in C(x)}\bar{H}(L)$。
  4. **标准解码**：在该长度上用最小熵解码（MED）去噪 $T=32$ 步。
- **候选比例集合（按方向设置）**：
  - En→Zh：$R=\{0.70, 0.75, 0.80, 0.85, 0.90\}$（中位数比例 0.80）
  - Zh→En：$R=\{1.00, 1.10, 1.20, 1.30, 1.40\}$（中位数 1.24）
  - En→De：$R=\{1.50, 1.60, 1.70, 1.80, 1.90\}$（中位数 1.48）
- **特点**：无需额外参数、无需参考长度、无需长度预测器、无开发集调参，训练后推理时仅增加最多 5 次前向传播探测（在 $T=32$ 时增加不超过 15.6% 的前向次数，实际因长度去重常更少）。

### 3. 实验设计

- **骨干与训练**：
  - 主实验：LLaDA-8B-Base，采用 LoRA（rank 64, α=128）在 WMT19 训练集上每个方向微调 20 万对（200k pairs），每方向 3 次独立训练。
  - 扩展骨干：Dream-v0-Base-7B（Qwen2.5-7B继续预训练）、DiffuLLaMA-7B（Llama-2-7B继续预训练）。
  - 对比AR基线：LLaMA-3-8B-Base + LoRA-SFT（相同微调数据）。
- **测试数据集与评测指标**：WMT22 新闻翻译测试集（每方向 2,037 句），COMET-22 与 sacreBLEU。
- **对比方法**：
  - 固定语料比例基线（Ratio，如 En→Zh 用 0.8）；
  - Length Oracle（使用参考目标长度，非部署方法，作为上界）；
  - 现有扩散长度方法：DAEDAL、CAL；
  - 揭示顺序（unmasking order）对照组：SIG-first、Reverse-SIG、Hybrid、Strict L2R、Random 等；
  - 多重候选解码后选优、固定比例网格搜参等。
- **人类评估**：3 名中英双语专业译者对 En→Zh 与 Zh→En 各 100 句做充分性（adequacy）与流畅度（fluency）1-5 评分和偏好判断。

### 4. 资源与算力

- 论文明确声明：整个实验网格约使用 **420 H20-96GB GPU 小时**。
- 训练配置：8×H20 GPU，global batch 128，bf16 精度，每方向训练 3 epochs，每方向 3 次独立运行（共 9 个检查点）。
- 推理耗时：En→Zh 在单张 H20、batch size 16 下，Ratio 约 1.5 秒/句，EV 约 1.7 秒/句。
- EV 在 $T=32/64/128$ 时最多增加 15.6%/7.8%/3.9% 前向传播次数。

### 5. 实验数量与充分性评估

- **实验规模相当充分**：
  - 三个翻译方向（En→Zh、Zh→En、En→De）各有 3 次独立训练重复；
  - 三种掩码扩散骨干（LLaDA-8B、Dream-Base-7B、DiffuLLaMA-7B）做跨模型验证；
  - 附加 De→Fr 方向作为无英语参与侧的语言对检查；
  - 大量消融与控制实验：候选宽度、固定比例网格扫参、前向预算控制、解码步数 Pareto（$T\in\{2,4,8,16,32,64,128\}$）、长度 vs 顺序解耦诊断、失败桶分析、显著性检验（paired bootstrap + Wilcoxon）等。
- **公平性**：与 AR 基线使用相同微调数据、相同 prompt 家族与 LoRA 配置；对比直接扩散长度基线时保持相同模型与评估协议；对 Ratio 基线给予了与 EV 相同或更多的计算预算以排除“额外计算”解释。
- **客观性**：包含错误类型分析（占位符保留率、数字保留率）、长度桶分析（$r<0.6, 0.6\leq r<0.8, r\geq0.8$）、失败案例分析，未回避边界情况。

### 6. 主要结论与发现

- **EV 有效提升翻译质量**：在 LLaDA 上，EV 相比固定比例基线在 COMET-22 上 En→Zh 提升 +0.0172、Zh→En 提升 +0.0165、En→De 提升 +0.0070；sacreBLEU 提升分别为 +1.85、+1.63、+0.82。
- **Gap 恢复率**：EV 恢复了参考长度（Length Oracle）相对固定比例基线 COMET 增益的 **64.9%（En→Zh）、65.3%（Zh→En）、33.0%（En→De）**。
- **EV 并非参考长度预测器**：去噪友好长度不一定匹配参考长度，但仍能取得良好翻译质量（图 5 中 EV 的长度 MAE 为 2.51，远高于 Oracle 的 0，却恢复了约 65% 的质量差距）。
- **长度选择比揭示顺序更重要**：固定参考长度条件下，六种源引导揭示顺序方案的 COMET 差异仅 0.0081；而固定 MED 条件下三种长度方法差异达 0.0265（约 3.3 倍）。
- **覆盖率改善**：En→Zh 上占位符保留率从 66.9% 提升到 89.1%，数字保留率从 77.6% 提升到 81.3%。
- **与 AR 基线对比**：在相同微调数据下，EV-LLaDA 在 En→Zh 与 LLaMA-3-8B 基本持平，在 Zh→En 上领先；但 En→De 上 AR 明显更强（这一差距即使给 LLaDA 参考长度也未能弥合，说明该方向瓶颈不在长度选择）。
- **跨骨干有效性**：在 Dream-Base 和 DiffuLLaMA 上，EV 在所有方向均优于固定比例基线，但 gap 闭合率因模型族而异（11.8%–68.7%）。
- **人类评估一致性**：Zh→En 上 EV 充分性得分优于 Ratio（+0.50），偏好投票 45 vs 25；En→Zh 上充分性也正向（+0.18），但多数为平局。流畅度差异较小。

### 7. 优点

- **方法简洁且训练无关**：仅利用模型本身的全掩码熵信号，不引入额外参数、预测器或训练目标，即插即用。
- **问题定位准确**：明确指出长度选择是掩码扩散 MT 中独立于揭示顺序的结构性瓶颈，并通过受控实验分离了两者的贡献。
- **实验设计严谨**：多方向、多骨干、多指标、多基线的组合验证，包含显著性检验、计算预算控制、失败分析、人类评估等，证据链完整。
- **诚实呈现局限性**：对 En→De 的弱证据、候选网格边界失败、Dream-Instruct 协议不匹配等问题均坦诚报告，没有只挑正面结果。
- **可复现性强**：公开代码、数据、LoRA 适配器、人类评估模板与完整超参配置。

### 8. 不足与局限

- **候选网格存在边界**：固定比例集合限制了 EV 能表达的长度范围。某些需要较强压缩的句子（如“Please give me a moment.” 需要 $r<0.7$）的熵谷落在网格之外，此时 EV 会劣于固定比例基线。论文自认下一步是压缩感知的候选生成器。
- **En→De 方向证据较弱**：语义级显著性测试（Wilcoxon）通过但 paired bootstrap 不显著，且 $T\geq64$ 时 EV 略低于固定比例基线，说明该方向长度选择收益有限、其瓶颈主要在别处（AR 基线远高于 EV 的 oracle 长度上限）。
- **人类评估覆盖有限**：仅覆盖 En↔Zh；En→De、De→Fr 等方向没有人类判断支持，依赖自动指标。
- **跨骨干差异未归因**：Dream-Base 与 DiffuLLaMA 同时改变了分词器、初始化、预训练数据和架构，无法确定哪种因素导致不同的 gap 闭合率。
- **候选网格需要人工选择**：虽然不使用参考长度和开发集调参，但报告的比例网格仍通过 WMT22 诊断子集比较选定，网格选择过程本身对结果有影响。
- **与 SOTA AR MT 存在差距**：LLaDA+EV 虽与同规模匹配数据 LLaMA 在中文方向持平或领先，但在 En→De 上大幅落后（约 8.8 COMET 分），说明掩码扩散用于高质量 MT 仍有漫长的路要走。
