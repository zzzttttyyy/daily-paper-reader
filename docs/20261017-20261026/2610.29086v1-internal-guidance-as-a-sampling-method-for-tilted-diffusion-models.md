## 摘要
奖励引导方法使用仅在基分布样本上训练的扩散模型，对基密度的指数倾斜进行采样。现有方法使用我们称之为外部引导的方法：漂移项中的加性项或转移概率上的乘性项。我们提出内部引导，它不修改基础去噪器的输出，而是改变其求值点。对于嵌入超立方体 $\{-1,1\}^{d}$ 的离散分布，任何线性倾斜密度的去噪器恰好等于在平移并重新缩放的输入处求值的基础去噪器。在实践中，基础去噪器是一个在基分布的加噪样本上训练的神经网络。对于基分布的基本加噪而言，采样倾斜密度所需的求值点将属于分布外。我们通过对数据施加随机对角重缩放来修改训练算法，使去噪器网络能够学习去噪器相对于基分布的分布内与分布外求值。单个去噪器网络无需微调且无需外部引导项，即可采样二元奖励倾斜、类别标签和填充。

## Abstract
Reward guidance methods sample an exponential tilt of a base density using a diffusion model trained with only samples from the base distribution. Existing methods use what we call external guidance: additive terms in the drift or multiplicative terms on the transition probabilities. We propose internal guidance which leaves the output of the base denoiser unmodified and instead changes the point at which it is evaluated. For discrete distributions embedded in the hypercube $\{-1,1\}^{d}$, the denoiser of any linearly tilted density is exactly the base denoiser evaluated at a shifted and rescaled input. In practice the base denoiser is a neural network trained on noised samples of the base distribution. The required evaluation points for sampling the tilted density would be out-of-distribution for basic noising of the base distribution. We modify the training algorithm with random diagonal rescalings of the data, so that the denoiser network learns both in- and out-of-distribution evaluations of the denoiser relative to the base distribution. A single denoiser network samples binary reward tilts, class labels, and infilling with no fine-tuning and no external guidance term.
