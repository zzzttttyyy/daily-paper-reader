## 摘要
图像变形旨在在两幅输入图像之间生成平滑且语义一致的过渡。现有的基于扩散的变形方法要么需要昂贵的逐对优化，要么依赖隐式空间对齐，在布局差异较大时容易失败。为解决这些局限，我们提出 AlignMorph，一种新颖的免调优扩散框架，遵循“先传输后去噪”的原则。我们显式地将几何对齐与生成式去噪解耦，以避免结构纠缠。我们的框架包含两个核心组件。(1) 全局语义传输，通过熵最优传输和可靠性感知的潜变量变形实现扩散兼容的语义对齐；(2) 坐标对齐生成，使用对称双阶段注意力交接，在去噪全程保持空间坐标一致。无需任何调优，AlignMorph 在变形基准上有效消除重影，并实现更优的结构连贯性和时间平滑性。代码见 https://github.com/51xOne/Alignmorph。

## Abstract
Image morphing aims to produce a smooth and semantically consistent transition between two input images. Existing diffusion-based morphing methods either require expensive per-pair optimization or rely on implicit spatial alignment, which easily fails under large layout discrepancies. To address these limitations, we propose AlignMorph, a novel tuning-free diffusion framework guided by the principle of transport-then-denoise. We explicitly decouple geometric alignment from generative denoising to avoid structural entanglement. Our framework consists of two core components. (1) Global Semantic Transport, which achieves diffusion-compatible semantic alignment via entropic optimal transport and reliability-aware latent warping; and (2) Coordinate-Aligned Generation, which uses a symmetric bi-phase attention handoff to maintain consistent spatial coordinates throughout denoising. Without any tuning, AlignMorph effectively eliminates ghosting and achieves superior structural coherence and temporal smoothness on morphing benchmarks. Code is available at https://github.com/51xOne/Alignmorph.

# AlignMorph 论文结构化总结

## 1. 核心问题与整体含义

- **研究背景**：图像变形（Image Morphing）需在两幅差异图像之间生成平滑、连续且语义一致的过渡序列，广泛应用于动画与创意工作流。与普通文生视频不同，变形同时受源图与目标图双重约束。
- **现有方法的局限**：
  - **基于优化的方法**（DiffMorpher、IMPUS）：通过逐对优化 LoRA 或潜变量嵌入获得高保真度，但计算开销极大，难以实用。
  - **免调优方法**（以 FreeMorph 为代表）：通过端点潜变量插值（如 Slerp）与注意力注入端点信息，效率高，但**隐式假设两端点已近似空间对齐**。
- **关键痛点**：当源图与目标图存在**大布局差异（large layout discrepancy）**时，隐式对齐失效，潜变量插值轨迹扭曲，导致**重影（ghosting）、半透明叠加、时序不连贯**等结构纠缠问题。
- **核心主张**：显式对齐应满足两个性质——**语义感知**（在高语义层面而非像素层面对齐）与**扩散兼容**（不破坏扩散去噪所需的噪声统计）。由此提出核心设计原则：**先传输几何，再去噪（transport-then-denoise）**。

## 2. 方法论

### 2.1 核心思想
显式解耦「几何对齐」与「生成式去噪」，在扩散采样前先建立可靠的语义几何对应，避免让扩散模型在采样过程中隐式处理严重布局差异。框架分两阶段：
- **阶段 Ⅰ 全局语义传输**：建立共享坐标框架下的端点潜变量对齐。
- **阶段 Ⅱ 坐标对齐生成**：在显式坐标一致约束下执行扩散采样。

### 2.2 阶段 Ⅰ-A：基于最优传输的语义对应
- 使用 **DINOv2 + FeatUp** 提取稠密语义特征 $F_S, F_T$，下采样为 token 集合 $\{x_i\}, \{y_j\}$，每个 token 关联 2D 空间坐标 $p_i, q_j$。
- 将稠密匹配建模为**最优传输（OT）**问题，传输代价用**余弦距离**：
  $$C_{ij} = 1 - \frac{\langle x_i, y_j \rangle}{\|x_i\|_2 \|y_j\|_2}$$
- 用**对数域 Sinkhorn 迭代**求解带熵正则的平衡 OT，得到传输方案 $T^\star$。
- 通过**重心投影（barycentric projection）**将概率方案转为确定性坐标映射：
  $$\Phi_{S\to T}(p_i) = \sum_j \bar{T}_{ij}\, q_j$$
- **可靠性权重**：结合 OT 置信度（行最大质量）与**前向-后向循环一致性误差** $\Delta(p_i)$，用高斯惩罚构造 $w(p_i) \in [0,1]$，用于过滤模糊/遮挡区域。
- 将模型空间映射转为位移场并双线性缩放至潜变量分辨率，得到潜变量形变算子 $\Phi^z_{S\to T}$ 与可靠性掩码 $w^z$。

### 2.3 阶段 Ⅰ-B：频率感知多频带潜变量传输
- 关键洞察：扩散潜变量同时编码**低频语义结构**与**高频纹理/随机噪声**；整体刚性形变会破坏高频统计，导致纹理模糊与采样不稳定。
- 将潜变量分解：$z = z_{\text{low}} + z_{\text{high}}$，其中 $z_{\text{low}}$ 由空间平均池化（$k=9$, stride 1, replicate padding）获得。
- 传输公式：
  $$z' = \underbrace{W(z_{\text{low}}; \Phi^z)}_{\text{几何引导}} + \underbrace{w^z \cdot W(z_{\text{high}}; \Phi^z) + (1-w^z)\cdot z_{\text{high}}}_{\text{统计保持}}$$
- 即**激进传输低频结构，按可靠性选择性保留高频噪声**，从而在不破坏扩散先验的前提下实现几何对齐。

### 2.4 阶段 Ⅱ：坐标对齐生成
- 基于传输后的潜变量构造两条方向路径（Slerp 插值）：
  $$z^L_i = \text{Slerp}(z_S, z_{T\to S}, \alpha_i),\quad z^R_i = \text{Slerp}(z_{S\to T}, z_T, \alpha_i)$$
- **中点融合**：将右中点以半强度传输映射回源帧后与左中点融合，减小帧交接处的不连续性。
- **对称双阶段注意力交接**：注意力输出为两分支加权：
  $$\text{Out}^l_{i,k} = (1-\lambda_i)\,\text{Attn}(Q, K^{(1)}, V^{(1)}) + \lambda_i\,\text{Attn}(Q, K^{(2)}, V^{(2)})$$
  - **早段帧（$i \le m$）**：$(z^{(1)}, z^{(2)}) = (z_S, z_{T\to S})$，记忆对齐源帧；
  - **晚段帧（$i > m$）**：$(z^{(1)}, z^{(2)}) = (z_{S\to T}, z_T)$，记忆对齐目标帧。
- 保证 query 与两个 K/V 分支始终处于同一几何坐标框架，避免跨帧检索冲突。

## 6. 主要结论与发现

- AlignMorph 在 MorphBench 与 Morph4Data 上**全面优于**优化类与免调优类基线（如 Morph4Data 上 LPIPS 74.23 / FID 188.44 / PPL 1896.30，优于 FreeMorph 复现版 79.56 / 203.32 / 1993.42）。
- 用户研究中 AlignMorph 偏好率达 **50.9%**，显著高于 FreeMorph（26.4%）、IMPUS（14.5%）、DiffMorpher（8.2%）。
- **消融结论**：
  - 随机 OT 严重退化 → 证明语义传输的必要性；
  - 去掉多频带 → 纹理模糊、细节丢失 → 证明高频噪声保持的必要性；
  - 去掉双阶段交接 → 轨迹被困于源坐标系、无法过渡到目标几何；
  - **去掉 KV warp 仍能生成结构连贯结果**，说明 **query 侧（输入潜变量）对齐是几何对齐的主要驱动力**，KV 对齐是提升纹理保真度的补充精修。
- **核心发现**：注意力本质是坐标敏感的检索算子——Q 决定"去哪里检索"，K/V 决定"检索什么"；大形变下的主导失效模式是 query 侧空间错位。
- **边界条件**：方法的适用边界不是形变幅度，而是**是否存在有意义的语义对应**。同类别大幅位移仍可建立可靠部件级对应；极端跨类别（如花→猴子）对应本身无效，方法会退化为以插值为主的轨迹。

## 7. 优点

- **范式创新**：提出"先传输后去噪"，将几何对齐与生成去噪显式解耦，从根本上规避结构纠缠，思路清晰且具有普适启发性。
- **语义对齐鲁棒**：用 OT + Sinkhorn 在语义特征空间建立稠密对应，而非传统像素级光流，能处理严重姿态差异与背景变化（如轮子对轮子、面部部件对位）。
- **扩散兼容性设计巧妙**：频率感知多频带传输在传输低频结构的同时保留高频噪声统计，解决"对齐 vs. 噪声保持"的矛盾；并用空间平均池化替代 FFT，兼顾质量与效率。
- **可靠性门控**：结合 OT 置信度与前向-后向循环一致性，能自动抑制不可靠区域的形变，避免错误扭曲。
- **免调优且高效**：无需逐对优化，单卡 RTX 3090 即可运行，比优化类方法快 20×–50×。
- **实验严谨**：严格沿用基线协议、额外复现 FreeMorph、补充用户研究、并诚实分析失败案例。

## 8. 不足与局限

- **语义对应依赖**：极端跨类别（无共享结构）时 OT 对应失效，方法退化为插值主导，显式对齐优势丧失；论文承认这需重新定义对齐目标与感知标准，留作未来工作。
- **基线覆盖有限**：主要对比对象仅 3 类（IMPUS、DiffMorpher、FreeMorph），缺少更多近期免调优变形/插值方法的比较。
- **评估规模有限**：用户研究仅 25 人，未报告统计显著性；定量实验未给出多次运行的方差或置信区间。
- **计算开销分布**：虽然免训练，但每对图像仍需 25 秒离线对应计算，对大规模批量场景仍有优化空间；且仅报告了 RTX 3090 单卡结果，未涉及更高分辨率或更长帧序列的扩展性。
- **潜在偏差风险**：指标（FID/LPIPS/PPL）主要衡量感知与保真度，对"语义合理性"的刻画有限；用户研究参与者背景偏学术，可能引入主观偏好偏差。
- **应用限制**：方法适用性受限于"端点间存在可建立的语义对应"，对艺术创作中刻意跨类别融合等开放场景支持不足。
