## 摘要
均匀状态离散扩散模型并行更新所有令牌，同时保持每个位置可修订。即使常用的top-p规则在某个位置只留下一个候选，该选择仅影响当前反向步骤，并可在下一步采样时修订。我们研究当所选假设成为后续预测的持久上下文时会发生什么变化。为此，我们提出了一种免训练的采样方法——承诺揭示采样（CRS），它存储所选argmax令牌并将其插入后续模型输入。我们的分析为后续选择以及保持所选令牌可见提供了理论依据。在精确前向过程下，选择干净令牌的贝叶斯误差不会随噪声降低而增加，而在一个简单的潜在模态模型中，保持所选令牌可见有助于后续并行预测在序列级选择上达成一致。实验上，在Duo蒸馏上的配对实验将这种持久效应与单步top-p限制和标量温度缩放区分开来。在相同的定稿规则下，无top-p截断的CRS在8至64次函数评估（NFE）的预算内达到比固定p=0.95和p=0.9基线更低的生成困惑度（GenPPL）。在64 NFE下，匹配单字熵的比较也显示CRS的GenPPL更低，产生更有利的GenPPL-熵权衡。基础Duo在描述性比较中显示相同方向，而其他多样性和延续性指标可能对这些操作点进行不同排序。这些结果表明支持限制和持久上下文是该权衡的独立控制因素。

## Abstract
Uniform-state discrete diffusion models update all tokens in parallel while keeping every position revisable. Even when the commonly used top-$p$ rule leaves only one candidate at a position, that choice affects only the current reverse step and can be revised at the next sampling step. We ask what changes when selected hypotheses instead become persistent context for later predictions. We therefore propose committed reveal sampling (CRS), a training-free sampler that stores selected argmax tokens and inserts them into subsequent model inputs. Our analysis gives a rationale for selecting later and for keeping selected tokens visible. Under the exact forward process, the Bayes error of selecting a clean token cannot increase as noise decreases, while in a simple latent-mode model, keeping the selected token visible helps later parallel predictions agree on the same sequence-level choice. Empirically, paired experiments on Duo-distilled then separate this persistent effect from single-step top-$p$ restriction and scalar temperature scaling. Under the same finalization rule, CRS without top-$p$ truncation reaches lower generative perplexity (GenPPL) than fixed $p=0.95$ and $p=0.9$ baselines across budgets of 8--64 function evaluations (NFE). At 64 NFE, the comparison at matched unigram entropy also gives lower GenPPL for CRS, yielding a more favorable GenPPL--entropy tradeoff. Base Duo shows the same direction in a descriptive comparison, while other diversity and continuation metrics can rank these operating points differently. These results identify support restriction and persistent context as distinct controls of that tradeoff.

**研究动机与背景：**

- 在均匀态（uniform-state）离散扩散模型（如 Duo）中，生成过程通过并行更新所有 token 逐步去噪，且每个位置始终可被修订。这与掩码扩散模型（如 MaskGIT）不同：后者一旦揭示某个 token，就固定了该部分的生成顺序，并作为后续更新的上下文。
- 实际使用的均匀态采样器常引入 top-p（核采样）来限制每次反向步中干净 token 的候选支持集。但 top-p 的支持限制是**单步的**：即使在生成后期 support 收缩为单一候选，该选择也仅作用于当前反向更新，下一步仍基于可修订的噪声状态重新计算预测，选中的标签不会显式保留到后续输入中。
- 论文核心追问：如果将选中的高置信假设作为**持久上下文**保留并注入后续模型输入，会对生成质量与多样性的权衡产生何种影响？

**整体意义：**

- 论文提出了免训练的 **CRS（Committed Reveal Sampling，承诺揭示采样）**，将逐步选定的 argmax clean token 存储并持久地写入后续去噪器输入，从而在均匀扩散模型中引入“承诺”机制。
- 理论上，论文证明了延迟选择（warmup）的合理性——更低的噪声不会增加最优选择误差；同时展示持久可见的标签可帮助后续并行预测趋向同一序列级模式。

## 2. 方法论

**核心思想：**

- CRS 将均匀离散扩散采样中的“点假设”（point hypothesis）从**仅用于当前步**转变为**持续可见的上下文**，通过引入显式历史决策记录来协调并行的位置独立预测，降低不同位置采样到互不兼容的序列级候选组合的风险。

**采样流程（以文字说明）：**

1. **热身阶段（Warmup）**：先运行原生可修订采样器若干步（按 warmup fraction 设定），不存储任何标签。
2. 在每个后续反向步中：
   - 将当前已存储的标签集合 C 写入去噪器输入，即构造 $x^{ext} = x_t[C \leftarrow c]$，使模型在预测时看到此前的承诺标签；
   - 在未选坐标中，按模型置信度（$1 - \max_a h^i_{\theta,t}(a | x^{ext})$）从高到低扫描，结合固定局部排斥规则（spacing radius）选择一批位置；
   - 将每个新选坐标的 argmax 标签存入集合，使其在后续步中保持可见；
   - 未选位置继续按原生可修订采样更新。
3. **最终解码**：所有方法统一使用坐标级 argmax 作为最终步输出（而非祖先采样），保证评价协议一致。

**数学理论支撑：**

- **Proposition 2（延迟选择）**：在坐标分解的均匀前向过程中，给定噪声水平 s < t，有 $R_i^s \le R_i^t$（oracle Hamming 选择误差不随噪声降低而增加），因此先热身再选择可降低错误承诺风险。
- **Theorem 1（持久可见性协调并行预测）**：在一个潜模态混合模型 $Q^{\mathrm{mix}}_w$ 与其边缘乘积 $Q^{\mathrm{prod}}_w$ 之间，KL 散度等于总相关项且不超过 $(n-1)\mathrm{Ent}(w)$。当可见上下文 U 与 Y 关于 M 条件独立时，如果标签使后验集中于某一模式，则 $D_{\mathrm{KL}}$ 上界随 ϵ(u) 减小而下降——即模式一致的可见标签可显著压低各坐标独立预测间的失配。
- **Theorem 3（组合支持证据与持久证据）**：将单步 top-p 的支持约束与持久可见上下文置于同一贝叶斯后验框架，两者作为“加性证据”共同降低对错误模式的后验权重，并推导出未来坐标并行预测的 KL 散度受后验误差 ε̄ 控制的上界。

## 6. 主要结论与发现

- **CRS 能显著降低 GenPPL**：在相同 64 NFE 与统一 argmax 最终解码下，Duo-distilled 上原生 p=1.0 的 GenPPL ≈ 41.79，p=0.95 ≈ 34.34，p=0.9 ≈ 29.76，而 CRS（Dmax=512，无 top-p）≈ 28.27，同时 unigram 熵仅从约 5.35 下降至 5.32，说明 CRS 以较小的多样性代价换取了更优的似然。
- **支持限制与持久上下文是分离的控制旋钮**：单步 top-p 只影响当前 reverse 步，而 CRS 将选定标签写入后续输入；标量温度无法解释 CRS 的路径改变（在共享状态下残差为 79.4% ± 2.1%），且 30.2% ± 0.8% 审计坐标的 top-1 发生变化。
- **延迟选择（warming up）是有益的**：更晚的选择保留较高的 unigram 熵且仍保持大量 GenPPL 增益；更晚开始选择会沿 GenPPL–熵曲线向高熵方向移动。
- **选择位置的审计显示**：base Duo 与 Duo-distilled 的主要差异不在同一固定位置下的 argmax 预测（二者几乎一致），而在于选择哪些位置进行承诺——蒸馏模型在更靠后的步骤中平均选择出略低的选择误差。
- **持久状态信息会传播**：将已承诺坐标恢复到可修订原值时，周围噪声状态仍能以较高概率预测原标签，说明信息已经通过自回归式上下文渗透到其他坐标。

## 8. 不足与局限

1. **评估器偏差风险**：主要质量评估使用 GPT-2-Large 与 Pythia，它们对低熵/保守文本可能天然给出更高似然，因此 GenPPL 指标的改善方向可能隐含对多样性的隐性惩罚；论文虽用熵匹配予以缓解，但其缓解只能覆盖 unigram 层面，无法完全覆盖 n-gram 或语义层面。
2. **辅助指标分歧**：Rep-4、Self-BLEU、固定前缀条件下不同评估器的排序并不总与 GenPPL–熵主结论一致——例如 GPT-2 偏好“每一步 p=0.8”而 Pythia 不能区分两种策略；说明结论对评估器与指标选择较敏感。
3. **实验范围受限**：仅在 Duo（蒸馏版与基础版）两个检查点上验证，未覆盖更大规模模型、其他均匀扩散结构（如 Sumi/GIDD）或更复杂的文本域；论文在结语中也明确承认这一点。
4. **基础版 Duo 对比为描述性**：base Duo 的前沿对比存在曲线折叠、非单调区间，未进行等效的定量匹配验证；表 2 中 base Duo 在不同启动批次的同配置数值也有漂移（如 78.31 vs 80.35），降低了结论的稳健性。
5. **计算资源不透明**：缺少 GPU 类型、总采样时间或碳排放信息；虽然 CRS 只需推理，但其逐步为每位置重新评估模型的累积推理成本大于原生采样，论文没有给出相对延迟或开销对比。
6. **理想化理论与自由运行不完全对齐**：Theorem 1/3 的证明依赖于精确条件独立与潜模态模型，正文也承认实际采样中的闭环 argmax 写回并不满足定理的理想化假设，理论结论只提供方向性洞见而非精确量化承诺。
7. **超参数敏感性**：CRS 的 Dmax、warmup 分数、spacing radius、count cap 等均被固定为若干启发式默认值，没有给出系统性的自动调参策略或在这些参数上的全谱行为分析；有限的低 NFE 设置中一个固定 Dmax 在不同 NFE 上的表现需要再调整。
