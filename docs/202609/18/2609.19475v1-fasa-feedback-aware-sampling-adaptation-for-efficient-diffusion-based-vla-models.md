## 摘要
基于扩散的视觉-语言-动作（VLA）模型在具身任务中表现优异，但其迭代采样会带来高昂的计算与内存访问开销，阻碍了在边缘平台上的实时部署。现有加速方法要么需要昂贵的训练（如蒸馏、流匹配），要么通过静态调度的剪枝与缓存损害感知能力，忽略了机器人交互中动态的工作负载变化。本文提出 FASA（反馈感知采样自适应），一种无需训练的运行时框架，将实时多模态反馈视为去噪流程的控制信号：交互驱动的范围适配器根据视觉与夹爪力反馈调节全局采样步数预算，而本体感觉感知的步长适配器在适配后的范围内精确定位优化步。这种协同设计框架使底层硬件架构能够自适应匹配不同执行阶段的工作负载需求。在多个基准上的对比评估表明，推理速度最高可提升至 1.45 倍，同时保持有竞争力的成功率，为将重型生成式具身 AI 工作负载部署到资源受限计算平台提供了一种新颖的动态运行时架构范式。

## Abstract
Diffusion-based Vision-Language-Action (VLA) models achieve strong performance in embodied tasks, but their iterative sampling imposes heavy computational and memory-access cost, blocking real-time deployment on edge platforms. Existing acceleration methods either require expensive training (e.g., distillation, flow matching) or degrade perception via statically scheduled pruning and caching, ignoring the dynamic workload variance of robotic interactions. This paper presents FASA (Feedback-Aware Sampling Adaptation), a training-free runtime framework that treats real-time multimodal feedback as a control signal for the denoising pipeline: an interaction-driven range adaptor modulates the global sampling-step budget based on visual and gripper-force feedback, and a proprioception-aware step adaptor pinpoints the optimized step within the adapted range. This co-designed framework allows the underlying hardware architecture to adaptively match the workload demands of different execution phases. Comparative evaluations across several benchmarks show that the inference speed can be increased by up to 1.45$\times$ while maintaining competitive success rates, providing a novel dynamic runtime architecture paradigm for deploying heavy generative embodied AI workloads onto resource-constrained computing platforms.

## 1. 核心问题与研究动机

- **背景**：基于扩散的视觉-语言-动作（VLA）模型通过迭代去噪建模多模态动作分布，在具身任务上性能强，但每个控制步需执行数百次去噪迭代，带来高延迟与能耗，难以在边缘平台实时部署。
- **现有加速路线的两类缺陷**：
  - **需训练的方法**（如一致性蒸馏、流匹配）：可减少采样步数，但需昂贵的重训练，且跨策略迁移性差。
  - **免训练方法**（视觉 token 剪枝、感知特征缓存、语言模型层早退）：其削减遵循**固定调度**或**输入级统计量**，而非交互实际所需的精度——在精度关键阶段削弱感知，在简单运动中又浪费算力。
- **核心洞察**：具身平台独有**实时反馈流**（视觉变化、夹爪力、本体感知）可作为去噪循环深度的控制资源。机器人任务在"精度关键阶段"（如接触丰富的操作）与"算力宽容阶段"（如粗略接近）之间交替，任何静态采样预算都无法匹配。
- **整体含义**：提出一种免训练、即插即用的运行时框架，把采样步预算的动态分配问题转化为由反馈驱动的闭环控制问题，为资源受限平台部署重型生成式具身 AI 提供新的动态运行时架构范式。

## 2. 方法论

### 2.1 核心思想

标准扩散策略在每个执行步以固定 K 步循环去噪。FASA 用**反馈条件化的调度**替换固定预算，采用两级协同设计：**全局范围调制 + 局部步长精定位**，由于去噪步数直接决定动作精度，FASA 在运行时动态分配该预算。

### 2.2 交互驱动采样范围自适应（Interaction-Driven Sampling Range Adaptation）

- **交互状态时变度量**（余弦距离，范围 [-1, 1]）：
  - 力变化：δ_force = −cos(F_t, F_{t−1})
  - 视觉变化：δ_vision = −cos(f_v,t, f_v,t−1)
  - 其中 F_t 来自机器人传感器或仿真物理引擎；f_v,t 由 VLA 模型**原有视觉编码器**从当前观测提取，以保证视觉反馈与策略表征对齐。
- **融合为调制因子**：α_t = ½·δ_vision + ½·δ_force + β，其中 β = 1.5 起**线性整流**作用：平滑准静态运动时变化项趋近 −1，β 保证乘子有正下界（α_t ≈ 0.5），防止生成崩溃。等权融合使两模态尺度一致，无需模态特定调参。
- **范围更新**：s_min^t = s_min^{t−1}·α_t，s_max^t = s_max^{t−1}·α_t；初始化满足 s_max^0 = 2·s_min^0。实现中对更新边界做**指数移动平均平滑**并裁剪到有效区间，避免剧烈振荡。
- **语义**：α_t < 1 在算力宽容的稳定阶段压缩执行路径；α_t > 1 在动态交互时分配更大算力预算。

### 2.3 本体感知采样步自适应（Proprioception-Aware Sampling Step Adaptation）

- **运动活跃度指标**：MotionIndex_t = ‖q̇_t‖ + ‖q_t − q_{t−1}‖，即瞬时关节速度与实现位置位移之和。两项均来自策略骨干已消费的**归一化本体感知状态**（逐关节标准化），因此量纲无量纲、可直接相加。
- **非线性门控映射**：s_opt^t = s_min^t + (s_max^t − s_min^t)·σ(MotionIndex_t)，σ 为 sigmoid。MotionIndex 越大（高动态阶段）→ 需要更细的时间分辨率 → 采样步越靠近范围上界。
- 由此实现**无训练**的扩散推理反馈驱动控制。

### 2.4 实现与开销

- 轻量、硬件无关的运行时模块，**拦截策略推理循环**，不修改模型权重、不修改机器人控制栈。
- 每步额外开销：一次策略视觉编码器调用、两次余弦相似度计算、MotionIndex 范数计算。
- 所需本体感知信号可通过标准物理引擎 API 或机器人控制接口普遍获取。
- 在 LIBERO 上使用**无力反馈变体**（该环境不提供夹爪力读数）。

- **RLBench**：平均成功率由 75.96% 提升至 77.48%，同时获得 **1.40×** 加速；close jar（30.67%→42.67%）与 stack blocks（54.00%→66.67%）提升显著，说明自适应采样在提升效率的同时不牺牲（甚至改善）任务执行质量。
- **ManiSkill3**：DP 由 70.28%→76.39%，加速 **1.45×**；RDT 由 86.11%→87.50%，加速 **1.23×**。跨策略可迁移；RDT（10 步采样）加速比较小，说明**加速空间随基线采样预算增大而增大**。
- **LIBERO**：无力反馈 FASA 将总体成功率由 93.0% 提升至 93.5%，加速 **1.23×**，平均去噪预算由 32 步降至 19.79 步；LIBERO-Long 达 1.35× 加速且成功率 +4 点；LIBERO-Spatial 下降 4 点（91.0→87.0），说明**细粒度空间控制需要更保守的调度**。

- **消融结论**：
  - 仅范围适配器：加速最高（1.64×，时间 33.59s→20.52s）但精度略降（77.22%→76.33%）。

## 7. 优点

- **问题定位精准**：抓住现有免训练加速方法"按固定调度削减、忽略交互动态需求"的本质缺陷，并将具身平台特有的实时反馈流明确定位为控制资源，视角新颖。
- **方法简洁且零训练成本**：无需重训练、无需修改权重、即插即用、硬件无关，工程落地门槛低；所有信号（夹爪力、视觉特征、关节位置/速度）均可通过标准接口获取。
- **设计细节有考量**：β = 1.5 的线性整流项防止平滑运动下的生成崩溃；等权融合保证尺度一致无需模态调参；EMA 平滑 + 裁剪抑制振荡；复用策略原有视觉编码器保证表征对齐；MotionIndex 使用已归一化状态保证两项可加。
- **两级协同设计合理**：全局范围调制负责"总量控制"，局部步长精定位负责"精度保障"，消融实验清晰地量化了两者的独立贡献与互补性。
- **泛化验证较广**：覆盖 4 个策略（含非 VLA 的 DP，作为扩散动作架构基础）、3 个基准、61 个任务条目、两种 GPU 平台，并额外验证无力传感变体。
- **多数场景下"提速且不掉点"**：在 RLBench、ManiSkill3（DP/RDT）与 LIBERO 总体上成功率不降反升，具备较强实用吸引力。

## 8. 不足与局限

- **仅仿真验证，缺乏真机实验**：所有结果来自 RLBench、ManiSkill3、LIBERO 仿真器，真实世界的传感噪声、力反馈延迟、视觉域差异均未涉及；作者亦在结论中承认这一点。
- **任务选择偏差风险**：ManiSkill3 只选 3 个任务，且明确是"RDT 基线表现最好的三个"，可能系统性高估泛化能力。
- **加速上限受限**：RDT 仅 10 步采样时加速仅 1.23×，说明方法对采样预算较小的策略收益有限；论文也承认加速空间与基线预算正相关。
- **精度在某些任务上下降**：RLBench 的 insert peg（73.33→69.33）、meat grill、place cup、put in safe、stack cups、turn tap 均有不同程度下降；

- **精度在某些任务上下降（续）**：RLBench 的 insert peg（73.33→69.33）、meat grill、place cup、put in safe、stack cups、turn tap 均有不同程度下降；LIBERO-Spatial 下降 4 点（91.0→87.0）。这表明反馈驱动的动态调度并非在所有任务上都"免费提速"——**高精度、细粒度空间控制任务对采样预算的削减更敏感**，而当前 α_t 与 σ(MotionIndex) 的映射并未显式区分"动态但需要精细控制"与"动态且可以粗放执行"两类情形。
- **反馈信号的语义粒度较粗**：视觉变化用策略原有视觉编码器特征的余弦距离度量，只能反映"表征层面变化了多少"，无法区分变化是来自目标移动、相机抖动还是干扰物出现；力信号同理只反映"力变了多少"，不区分是正常接触建立还是碰撞异常。这种**无差别的"变化量"驱动**可能在需要区分变化类型的场景下误判。
- **超参数依赖与敏感性问题未探究**：β = 1.5、等权融合的 ½/½ 系数、EMA 平滑系数、裁剪区间、s_max^0 = 2·s_min^0 的初始比例等均为手工设定，论文未给出敏感性分析，也未说明这些值是否跨策略/跨基准需要重新调参。
- **对比基线单一**：主要与各策略的固定采样基线对比，未与已有的免训练加速方法（如视觉 token 剪枝、感知缓存、层早退等）做直接横向比较，因此"反馈驱动优于输入级统计驱动"这一核心主张缺少直接的实验证据，仅停留在动机论证层面。
- **评估统计严谨性不足**：未报告随机种子数量、成功率方差/置信区间、显著性检验；Table I 与 Table IV 对同一基线（3D-DA）给出的成功率不一致（75.96% vs 77.22%）却未解释口径差异，削弱了数值可信度。
- **篇幅限制导致细节缺失**：仅 4 页，方法中关于 EMA 平滑的具体形式、裁剪边界、初始化 s_min^0 的取值、无力反馈变体中 α_t 退化为仅视觉项的具体处理等关键实现细节均未完整给出，复现性受限。
- **运行时开销的量化不充分**：额外视觉编码器调用是主要开销，但论文仅定性称"轻量"，未给出其占单步总延迟的比例；当策略本身使用重视觉骨干时，该开销可能抵消部分加速收益，而这一边界条件未被讨论。

## 9. 总体评价与启示

- **定位**：FASA 是一篇**方法论创新明确、工程导向强、篇幅精简**的短论文，核心贡献是提出"用机器人自身的实时反馈流来闭环控制扩散去噪预算"这一运行时范式，而非追求 SOTA 性能。
- **最大价值**：把"免训练加速"的削减依据从**静态调度/输入统计**推进到**交互闭环**，为资源受限平台部署重型生成式具身策略提供了一条低成本路径；其两级设计（范围调制 + 步长精定位）具有较好的模块化借鉴意义。
- **核心风险**：证据全部来自仿真、任务选择存在偏差、超参数敏感性未知、缺少与同类免训练方法的直接对比——这些使其"普遍有效"的主张尚需更强证据支撑。
- **后续可探索方向**（基于论文自身暴露的局限推断）：
  1. 引入**真机验证**，考察传感噪声与力反馈延迟对闭环调度稳定性的影响；
  2. 让 α_t 的构造具备**变化类型判别能力**（如区分目标运动与相机抖动、正常接触与异常碰撞），而非仅用变化幅度；
  3. 将**空间精度需求**显式建模（如结合任务阶段或末端执行器与目标的相对位姿），缓解 LIBERO-Spatial 类任务掉点问题；
  4. 与 token 剪枝、缓存、层早退等免训练方法**正交组合**，验证反馈调度能否叠加于其上；
  5. 补充超参数敏感性、随机种子方差与显著性分析，并统一各表格的评估口径。

## 10. 一句话总结

FASA 提出一种**免训练、即插即用**的反馈感知采样自适应框架，用视觉变化、夹爪力与本体感知构成的实时反馈闭环，动态分配扩散式 VLA 模型每个控制步的去噪预算，在 RLBench、ManiSkill3、LIBERO 上实现约 1.2×~1.5× 的动作生成加速且总体成功率不降反升，为生成式具身策略的实时部署提供了新思路，但真机验证、超参数敏感性与同类方法横向对比仍待补足。
