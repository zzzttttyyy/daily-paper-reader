## 摘要
我们旨在通过在不改变模型权重或外部采样器的情况下，在去噪器内部增加推理计算，来改进冻结的流匹配图像生成器。现有的生成器通常通过增加采样步骤来增加测试时计算，这会重复评估整个去噪器，并将质量提升与采样器成本耦合在一起。一个关键挑战是如何在冻结的Transformer去噪器内部使用额外的计算：该方法必须决定哪些令牌、层和采样时间接受重复更新，同时保留原有的生成流程。我们引入了一个免训练的循环框架，该框架在每次去噪调用中反复应用选定的Transformer层。密集与稀疏令牌循环改变令牌范围；采样进度门控和循环层范围指定循环何时何地激活；循环次数和强度控制重复更新；循环引导结合普通和循环向量场预测。在两个Scale-RAE模型规模上，循环变体改善了主要和辅助质量指标，并具有竞争性的质量-效率权衡。循环引导进一步提升了所有三个测试模型的主要指标；在Scale-RAE DiT2.4B上，它将GenEval从0.4471提升至0.5691，将DPG-Bench从0.7656提升至0.8053。代码将发布。

## Abstract
We aim to improve frozen flow-matching image generators by adding inference computation inside the denoiser, without changing model weights or the outer sampler. Existing generators usually spend extra test-time computation by increasing the number of sampling steps, which repeatedly evaluates the entire denoiser and couples quality gains to sampler cost. A key challenge is how to use extra computation inside a frozen transformer denoiser: the method must decide which tokens, layers, and sampling times receive repeated updates while preserving the original generation pipeline. We introduce a training-free looping framework that repeatedly applies selected transformer layers inside each denoising call. Dense and Sparse Token Loop vary the token scope; Sampling-Progress Gating and the loop layer range specify when and where looping is active; loop count and strength control the repeated updates; and Loop Guidance combines ordinary and looped vector-field predictions. Across two Scale-RAE model scales, loop variants improve primary and auxiliary quality metrics with competitive quality--efficiency trade-offs. Loop Guidance further improves both primary metrics across all three tested models; on Scale-RAE DiT2.4B, it raises GenEval from 0.4471 to 0.5691 and DPG-Bench from 0.7656 to 0.8053. Code will be released.

## 2. 论文提出的方法论

### 核心思想

通过"循环"（looping）在冻结的流匹配去噪器内部添加推理计算，从四个维度组织设计：

1. **What（重复什么）**：Dense Token Loop vs. Sparse Token Loop（令牌范围）
2. **When（何时激活）**：Sampling-Progress Gating（采样进度门控）
3. **Where（何处应用）**：Loop Layer Range（循环层范围）
4. **How（如何控制效果）**：Loop Count（循环次数）、Loop Strength（循环强度）、Loop Guidance（循环引导）

### 关键技术细节

#### 朴素内部循环（Naive Internal Looping）
直接对某一层循环应用K次，但会产生过大的隐藏状态位移、忽视层深度和采样进度的差异、计算成本高。

#### Dense Token Loop
将所选层的重复更新控制为残差更新的形式：
- 定义残差映射：*Rⱼ(Z; t, c) = Lⱼ(Z; t, c) − Z*
- 重复K轮，每轮强度 *η = λ_loop / K*：
  - *Z⁽⁰⁾ = hⱼ*
  - *Z⁽ʳ⁾ = Z⁽ʳ⁻¹⁾ + ηRⱼ(Z⁽ʳ⁻¹⁾; t, c)*
  - *hⱼ₊₁ = Z⁽ᴷ⁾*
- 当 *K = 1* 时恢复普通层输出；*λ_loop = 1* 为默认设置。

#### Sampling-Progress Gating
- 基于"粗到细"的降噪轨迹，高噪声阶段的调用对文本对齐内容和全局布局影响大，低噪声阶段主要去除残噪和锐化细节。
- 给定 *s_end ∈ [0, 1]*，循环激活区间为 *S_loop = [0, s_end]*，即只在采样前半段激活循环。

#### Sparse Token Loop
- 减少计算量：只对选定的token子集进行重复计算，保留全token上下文。
- 关键设计是"初始化一次"：在循环前仅缓存一次补集token的残差 *C_X̄*，后续每轮只更新选定token的残差，补集token复用缓存残差。
- 选取方式为均匀随机抽样，比例 *ρ_sel* 控制选定token比例。

#### Loop Guidance
- 预测空间控制机制：组合普通向量场预测与循环向量场预测：
  - *v_base = v_θ(xₜ, t, c)*
  - *v_loop = v_loop_θ(xₜ, t, c)*
  - *v_lg = v_base + g_lg(v_loop − v_base)*
- 尺度 *g_lg* 控制循环诱导校正的强度，*g_lg > 1* 时进行外推。

## 6. 论文的主要结论与发现

1. **内部循环有效**：在两个Scale-RAE模型规模上，Dense Token Loop和Sparse Token Loop均显著提升GenEval和DPG-Bench主要指标及辅助指标。

2. **Loop Guidance全面有效**：在三个RAE生成器上均提升两个主要指标，且在GenEval和DPG-Bench上实现一致的辅助指标增益：
   - Scale-RAE DiT2.4B：GenEval从0.4471提升至**0.5691**，DPG-Bench从0.7656提升至**0.8053**
   - Scale-RAE DiT9.8B：GenEval从0.5321提升至**0.6432**，DPG-Bench从0.8003提升至**0.8264**
   - RAEv2 SigLIP2-B：GenEval从0.3829提升至**0.4532**，DPG-Bench从0.7131提升至**0.7521**

3. **质量-效率优势**：25步Dense Token Loop（2.18秒）优于50步无循环基线（2.40秒，0.4742 GenEval），表明内部循环比单纯增加外采样步数更高效。

4. **设计准则**：
   - 中后段层范围（[12, 27]）最优，优于早期层和全层循环
   - 采样前段（[0, 0.5]）激活循环最有效
   - 中等循环次数（K = 4）最佳，收益递减
   - 中等Loop Guidance尺度最优，过大尺度反而减弱收益

5. **Sparse Token Loop效率优势**：相比Dense Token Loop在DiT2.4B上节省22.6%时间、DiT9.8B上节省39.6%时间，但质量略低。

6. **方法边界**：
   - 在VAE生成器（PixArt-alpha、FLUX.2）上迁移效果不一致
   - 在GenEval2上无法修复计数和空间组合错误
   - 稀疏化策略的定向选择（条件感知、注意力感知）未显著优于随机选择

## 8. 不足与局限

### 实验覆盖方面
- **VAE生成器不兼容**：在PixArt-alpha和FLUX.2上未观察到一致改进，方法适用范围有限，仅对RAE类生成器有效。
- **RAEv2无引导时提升微弱**：未使用Loop Guidance时，RAEv2的GenEval略微下降（0.3829→0.3795），"直接迁移的转移结果是混合的"。
- **无法修复所有错误类型**：GenEval2上计数和空间组合错误依然存在，且循环有时会削弱或移除请求的背景。
- **稀疏化策略效果有限**：尝试的条件感知和注意力感知路由并未超越随机选择，缺乏更有效的任务感知稀疏化器。

### 偏差风险方面
- **固定种子评估**：无法估计跨随机种子的波动，论文明确不作统计显著性声明。
- **超参数调优深度有限**：Loop Guidance尺度未穷举调优，不同指标偏好的最优尺度不一致（GenEval偏好*g_lg* = 2.8，DPG-Bench偏好*g_lg* = 2.0）。

### 应用限制方面
- **时间开销问题**：Dense Token Loop在DiT2.4B上耗时增加约67%（1.31秒→2.18秒），在DiT9.8B上增加约140%（1.69秒→4.04秒）。
- **小模型稀疏无优势**：在615M模型上，Sparse Token Loop反而比Dense Token Loop更慢（1.36秒 vs 1.10秒），路由开销在小规模下无法抵消。
- **机制不明确**：论文承认"主体层面校正的机制仍是开放的"，缺乏对循环为何有效的理论解释。
