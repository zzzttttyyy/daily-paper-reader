## 摘要
视频生成在内容创作和娱乐领域具有广泛应用。扩散Transformer提升了生成视频的质量，但随着视频分辨率和时长的增加，对时空token的注意力变得愈发昂贵。我们提出DraftAttention2，一个无需训练的框架，它利用低分辨率草稿注意力图来联合选择注意力块并分配其数值精度。具体而言，空间二维平均池化和最大池化后的查询与键捕获互补的区域统计信息，以估计块重要性；共享排序将更高精度分配给重要块，将较低精度分配给次重要的保留块，并在可配置预算下跳过其余块。我们的分析将稀疏化误差与注意力加权量化误差分离，确立了何时用低比特计算恢复被跳过的交互能够收紧输出误差界。这一分析促使在低精度下保留更多交互，同时为注意力权重总量更大的块保留更高精度。为了将这些细粒度分配转化为实际加速，我们进一步开发了融合的操作数准备以及一个具有精度特定阶段的单一注意力核，在不同精度间共享数据移动、softmax统计量和输出累加。实验表明，我们的方法相比现有高效视频生成方法实现了更优的质量-效率权衡。值得注意的是，其优势在少步视频扩散中尤为明显，此时将稀疏性与4位和8位混合精度计算相结合，可显著提高生成质量，同时保持显著加速。代码见 https://github.com/anemoi-project/anemoi

## Abstract
Video generation has broad applications in content creation and entertainment. Diffusion transformers have advanced the quality of generated videos, but attention over spatiotemporal tokens becomes increasingly expensive as video resolution and duration increase. We present DraftAttention2, a training-free framework that uses the low-resolution draft attention map to jointly select attention blocks and assign their numerical precision. Specifically, spatial 2D average- and max-pooled queries and keys capture complementary regional statistics to estimate block importance, and a shared ranking assigns higher precision to important blocks, lower precision to less important retained blocks, and skips the rest under configurable budgets. Our analysis separates sparsification error from attention-weighted quantization error, establishing when recovering skipped interactions with low-bit computation tightens the output-error bound. This analysis motivates retaining more interactions at low precision while reserving higher precision for blocks with larger attention mass. To translate these fine-grained assignments into practical speedups, we further develop fused operand preparation and a single attention kernel with precision-specific phases, sharing data movement, softmax statistics, and output accumulation across precisions. Experiments demonstrate that our method achieves a superior quality-efficiency trade-off over existing efficient video generation methods. Notably, its advantage is particularly pronounced for few-step video diffusion, where jointly combining sparsity with 4- and 8-bit mixed-precision computation substantially improves generation quality while retaining significant acceleration. Code is available at https://github.com/anemoi-project/anemoi

## 1. 核心问题与研究动机

- **背景**：视频扩散模型（Video Diffusion）基于 Diffusion Transformer（DiT），通过注意力建模时空 token 依赖，但注意力计算量随视频分辨率和时长呈二次增长，且在每个去噪步重复，成为 DiT 推理的主要瓶颈。
- **现有方法局限**：
  - 稀疏注意力通过保留部分注意力交互降低开销，但直接跳过交互会丢失信息。
  - 低比特/量化注意力可提升矩阵乘吞吐，但统一低精度会引入较大量化误差。
  - 已有混合精度方法多关注块级选择，但较少将“稀疏选择”与“精度分配”在统一预算下联合优化。
- **论文核心问题**：如何在免训练条件下，对视频扩散注意力同时进行块稀疏化和混合精度分配，从而在给定计算预算下取得更优的质量-效率权衡，尤其是在少步视频扩散中。
- **整体含义**：DraftAttention2 将传统“保留或跳过”的二值块稀疏决策，推广为“跳过 / 4-bit / 8-bit / 16-bit”的联合稀疏-精度分配，并利用低分辨率 draft 注意力图作为统一重要性排序依据。

## 2. 方法论

### 2.1 核心思想

- 使用低分辨率 draft 注意力图估计区域对的重要性。
- 对每个注意力头内的所有视频区域对进行统一排序，并按配额分配：
  - 最重要区域对使用 16-bit；
  - 次重要区域对使用 INT8；
  - 再次区域对使用 NVFP4；
  - 其余区域对跳过。
- 保留块仍参与共同的 softmax 归一化和输出累加，避免分精度独立输出与额外合并核。

### 2.2 关键技术细节

- **空间区域划分**：将每帧划分为连通区域，区域 token 数受注意力块容量约束，并与后续连续注意力块对齐。
- **平均与最大池化描述子**：
  - 对每个区域计算平均描述子 \(\bar{Q}_a, \bar{K}_b\)；
  - 同时计算通道维最大描述子 \(Q^{max}_a, K^{max}_b\)；
  - 平均池化保留区域平均 logit，最大池化提供均值之外的通道变化信息。
- **Draft 注意力图**：
  - 定义混合权重 \(\lambda \in [0,1]\)：
    \[
    A = (1-\lambda)\,\text{softmax}_{row}\left(\frac{\bar{Q}\bar{K}^\top}{\sqrt{d}}\right)
      + \lambda\,\text{softmax}_{row}\left(\frac{Q^{max}(K^{max})^\top}{\sqrt{d}}\right)
    \]
  - 对每个头内所有区域对按 \(A_{ab}\) 降序排序。
- **联合稀疏-精度分配**：
  - 给定头级配额 \(T_{16}, T_8, T_4\)；
  - 前 \(T_{16}\) 个区域对分配 16-bit；
  - 接下来 \(T_8\) 个分配 INT8；
  - 接下来 \(T_4\) 个分配 NVFP4；
  - 其余置为 0，即跳过。
  - 每个区域对继承同一精度到其物理注意力块；查询区域可自适应获得不同数量的保留块和不同精度组合。
- **理论分析**：
  - **Lemma 3.3**：将输出误差分解为稀疏化误差与注意力加权量化误差：
    \[
    \|O^{dense}_u - \hat{O}_u\|_2
    \le 2V_{max}\delta_u + m^{(8)}_u\varepsilon_8 + m^{(4)}_u\varepsilon_4
    \]
    其中 \(\delta_u\) 为被跳过的稠密注意力质量，\(m^{(p)}_u\) 为分配给精度 \(p\) 的保留注意力质量。
  - **Proposition 3.4**：在保留相同 16-bit 支持的前提下，比较 DraftAttention v1 稀疏分配与 DraftAttention2 混合精度分配，给出低比特恢复优于纯稀疏的条件。
  - **Theorem 3.6**：在固定支持与精度配额下，将高精度分配给注意力质量更大的区域对，可最小化误差界，为 draft 排序分配提供理论依据。
- **硬件高效执行**：
  - **紧凑 ragged 2D 打包**：将空间区域打包为连续块，减少 padding，保持空间局部性。
  - **融合操作数准备**：将 Q/K 重排、平均/最大池化、量化融合为一个核；V 重排与转置融合进操作数打包与加载。
  - **单核分阶段执行**：将每个查询块的保留键块按 NVFP4、INT8、16-bit 分段，在同一个注意力核中依次处理。
  - **跨精度累加**：所有阶段共享 FP32 行最大值、指数和与输出累加器；阶段边界仅做轻量缩放，避免每精度独立输出和额外 merge kernel。
  - 精度切换次数仅取决于活跃格式数，最多 2 次，与保留块数无关。

### 2.3 算法流程简述

1. 对 Q、K 按空间区域做平均池化与最大池化。
2. 计算混合 draft 注意力图 \(A\)。
3. 对每个头内所有区域对按 \(A\) 排序。
4. 按配额分配 16-bit、8-bit、4-bit 或跳过。
5. 将区域精度映射到全分辨率注意力块。
6. 融合重排、池化、量化，准备各精度操作数。
7. 在单一注意力核中按精度阶段执行，共享 online softmax 状态。
8. 统一归一化输出，恢复 token 顺序。
