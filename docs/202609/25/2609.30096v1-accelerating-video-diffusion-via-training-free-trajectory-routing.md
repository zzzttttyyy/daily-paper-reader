## 摘要
视频扩散的计算开销很大，因为它需要在许多去噪步骤中执行一个大模型。即使采用步数蒸馏，推理仍然昂贵，因为每个蒸馏步骤仍需要进行一次代价高昂的模型评估。我们提出 TRACK：通过 top-K 选择实现的轨迹感知容量路由（TRajectory-Aware Capacity routing via top-K selection），这是一种异构去噪策略，在选定的步骤在兼容的大模型和小模型之间切换，从而降低每次去噪评估的平均成本。切换步骤通过校准过程确定。TRACK 首先用大模型展开一条参考轨迹。然后在每一步，同时收集小模型的预测，并将其与大模型的预测进行比较，得到相对分歧分数。两个模型接收相同的潜在表示、时间步、条件输入和引导输入。在校准集上聚合该信号，可得到跨扩散步骤的分歧分数图，从而确定高效推理过程的切换策略：对质量敏感的步骤继续使用大模型，而分歧分数低的步骤则路由到小模型。推理在每一步仅执行所选模型，无需重新训练、无需更改架构或调度器，也无需在线双模型评估。在 Wan 2.1、Cosmos 3、TurboDiffusion 和 FastVideo 上，TRACK 分别实现了 1.95 倍、2.04 倍-2.73 倍、2.69 倍和 2.17 倍的加速，同时具有可比的总体质量和较高的多样性保持能力。因此，TRACK 将自动化的免训练模型切换确立为视频扩散的一种实用加速范式。

## Abstract
Video diffusion is computationally expensive, as it requires executing a large model across many denoising steps. Even with step-distillation, inference remains expensive because every distilled step still requires a costly model evaluation. We present TRACK: TRajectory-Aware Capacity routing via top-K selection, a heterogeneous denoising strategy that switches between compatible large and small models at selected steps, reducing the average cost per denoising evaluation. The switching steps are determined using a calibration process. TRACK first rolls out a reference trajectory with the large model. Then at each step, the small model's prediction is also collected and compared against the large model's prediction to obtain a relative disagreement score. Both models receive the same latent, timestep, conditioning, and guidance inputs. Aggregating this signal over a calibration set produces a disagreement score map across diffusion steps, which determines a switching policy for an efficient inference process: quality-sensitive steps keep using the large model, while steps with low disagreement scores are routed to the small model. Inference executes only the selected model at each step, requiring no retraining, architecture or scheduler changes, or online dual-model evaluation. Across Wan 2.1, Cosmos 3, TurboDiffusion, and FastVideo, TRACK yields $1.95\times$, $2.04\times$-$2.73\times$, $2.69\times$, and $2.17\times$ speedups, respectively, with comparable aggregate quality and high diversity retention. TRACK thereby establishes automated, training-free model switching as a practical acceleration paradigm for video diffusion.

# 论文总结：Accelerating Video Diffusion via Training-Free Trajectory Routing（TRACK）

## 1. 核心问题与研究动机

- **背景**：视频扩散模型（如 Wan 2.1、Cosmos 3）能生成高保真、时序一致的视频，但采样需要在**高维时空潜变量**上反复执行**数十亿参数的去噪器**，推理延迟成为部署的首要瓶颈。
- **现有加速路线及其局限**：
  - *减少步数*：蒸馏、少步目标（DMD、LCM、SD-Turbo、SDXS）、快速 ODE 求解器（DPM-Solver）等——但需要额外训练，且存在模型/预算相关的质量权衡。
  - *降低单步成本*：特征缓存、流式执行、Token 合并、稀疏计算、滑窗注意力等（FastVideo、TurboDiffusion 等）——但这些都在"步数已定"的前提下工作。
- **被忽视的冗余**：一旦采样器与步数确定，**剩余的所有去噪评估仍被统一分配给同一个模型、按相同成本计费**。因此存在一个互补的优化维度：**降低每步的平均模型成本**，从而与"步数削减"形成乘积式增益，而非竞争关系。
- **核心难点**：朴素的模型切换（按固定/启发式时间边界、单向一次性交接）无法刻画视频生成的复杂时空动态。两个模型可能在**总体预测误差相近**的情况下，在特定时间步于空间细节、相机运动、帧间一致性上出现分歧；未经校准的容量削减还可能破坏结构承诺、导致样本多样性崩塌。
- **论文定位**：提出 **TRACK**（TRajectory-Aware Capacity routing via top-K selection），把"轨迹容量分配"转化为一个**离线校准问题**，实现自动化、免训练、逐步的异构去噪切换。

## 2. 方法论

### 2.1 核心思想
- 给定共享潜空间与调度器的**兼容大/小检查点对**（如 Wan 的 14B/1.3B），先用大模型 rollout 一条**全大模型参考轨迹**；在每个去噪步用**完全相同的输入**（潜变量 $x_{t_k}$、时间步、正/负条件、引导尺度）评估两个去噪器，度量二者的**归一化相对分歧**；将分歧在校准集上聚合，得到逐步分歧分数图 $q_k$；据此生成离线切换策略 $\pi$，推理时**每步只执行一个模型**。

### 2.2 形式化设定
- 去噪预测（含 CFG）：
  $$p_m(x_{t_i}, t_i) = f_m(x_{t_i}, t_i, \varnothing) + w\big(f_m(x_{t_i}, t_i, \tau) - f_m(x_{t_i}, t_i, \varnothing)\big)$$
- 调度器更新：$x_{t_{i+1}} = \mathcal{S}(x_{t_i}, p_m(x_{t_i}, t_i), t_i, h_i)$
- TRACK **只改变** Eq.(2) 中由哪个模型提供 $p_m$，保持时间步序列、预测目标、调度器与调度器状态演化不变：
  $$x_{t_{i+1}} = \mathcal{S}\big(x_{t_i}, p_{\pi(i)}(x_{t_i}, t_i), t_i, h_i\big)$$
- **兼容模型对的要求**：共享潜表示、输出形状、条件接口、预测目标与调度器语义；内部架构与参数量可不同，但引导预测对调度器必须语义等价。

### 2.3 离线校准：归一化预测分歧
- 校准集 $\mathcal{D}=\{d_j\}_{j=1}^{M}$。对每个 prompt 用大模型 rollout 完整轨迹；**在每个调度器更新之前**，在同一个参考潜变量上同时评估大、小模型（记录后仍由**大模型预测**推进轨迹，保证后续探针始终位于全大模型参考路径上）。
- 归一化分歧（以**大模型预测幅度**归一化）：
  $$r_{j,k} = \frac{\big\|p_S(x^{(j)}_{t_k},t_k) - p_L(x^{(j)}_{t_k},t_k)\big\|_2}{\max\big(\|p_L(x^{(j)}_{t_k},t_k)\|_2,\ \epsilon\big)}$$
- 跨 $M$ 个 prompt 取均值得到逐步分歧分数：$q_k = \frac{1}{M}\sum_j r_{j,k}$。$q_k$ 越低表示大小模型越一致，越适合路由到小模型。

### 2.4 Top-K 切换策略的优化推导
- 定义平方分歧代价 $W_k = q_k^2$，松弛切换变量 $\beta_k \in [0,1]$，使用小模型的收益为 $-C_0\sum_k \beta_k$（$C_0$ 为用户指定的成本常数，如硬件延迟），得到盒约束问题：
  $$\arg\min_{\beta_0,\dots,\beta_{N-1}\in[0,1]} \sum_k (W_k - C_0)\beta_k$$
- 目标函数**线性且可分离**，故最优解为 $\beta_k^\star = 1$ 当 $W_k < C_0$，否则为 $0$（$W_k=C_0$ 时可取整数解）。
- **固定切换预算 $K$** 时，只需把 $q_k$（等价于 $W_k$）最小的 $K$ 步路由到小模型；选择 $C_0$ 落在第 $K$ 与第 $K+1$ 小的 $W_k$ 之间即可精确选出这 $K$ 步——因此"指定 $C_0$"等价于"指定 $K$"，无需混合整数建模，且可**连续或非连续**地切换。

### 2.5 推理
- 严格按离线策略 $\pi$ 执行，每步只跑一个检查点，潜变量、条件与调度器状态在大小模型间无缝传递；**无学习式路由模块、无在线双模型评估**。
- 总去噪成本约为 $\sum_i C_{\pi(i)}$（$C_m$ 为模型 $m$ 单次评估的墙钟延迟），不含文本编码、解码与调度器开销；校准是一次性离线设置，**部署时零额外开销**。

## 6. 主要结论与发现

- **加速效果**：在四条管线上实现 **1.95×–2.73×** 的端到端加速，且保持与原全大模型管线**可比**的总体质量；在 3 步与 4 步的蒸馏管线上仍有效，说明本方法与步数蒸馏**互补而非竞争**。
- **分歧的 U 形结构**：Wan 2.1 与 Cosmos 3 的分歧分数在**首尾高、中段低**（最低点落在轨迹后半段）。频带分解显示：早期分歧由**低频**主导（全局结构承诺阶段），后期分歧转向**中高频**（细节精修阶段）；因此中段是最安全的切换区间，最后几步应"切回"大模型。
- **蒸馏模型的差异**：TurboDiffusion 与 FastVideo 的分歧从第一步起**单调下降**、无末期回升，且始终由**低频**主导，因此切换策略在少步场景下自然落在前段。
- **相对启发式策略的优势**：在等预算下，Top-$K$ 在质量与多样性上均优于 First-$K$、Last-$K$、Random-$K$ 与 SRDiffusion。First-$K$ 因替换了决定生成多样性的早期步而多样性损失最大；Last-$K$/SRDiffusion 因单向永久交接，无法在末期高频细节阶段切回大模型。
- **多样性保持**：TRACK 保留 **>95%** 的大模型样本多样性（各管线 95.7%–104.8%），复现了图像扩散中的保持动态。
