## 摘要
多智能体交互世界模型不仅应生成一致的观测结果，还应维护跨智能体持续存在且随视角演化的世界状态。现有的自回归视频扩散流程将观测历史作为条件上下文传递，这使得在多智能体和多视角设置中难以维护共享状态。我们提出了WorldWeaver (W^2)，一种流式多智能体视频扩散模型，通过跨智能体世界状态寄存器增强生成过程：这些可学习标记存储共享世界信息，跟踪个体智能体状态，并在每个生成块之后动态更新。我们利用跨越个体智能体状态、全局状态视图（包括鸟瞰图）和场景文本的监督信号来锚定这些寄存器。我们进一步通过混合Transformer设计改进了架构，该设计使用独立的权重进行世界状态建模和视觉帧建模。在两个智能体的Minecraft视频生成中的大量实验表明，显式的世界状态建模提高了逻辑一致性和生成质量。

## Abstract
Multi-agent interactive world models should not only generate consistent observations, but also maintain world states that persist across agents and evolve across views. Existing autoregressive video diffusion pipelines carry forward observation history as conditioning context, which makes shared state difficult to maintain in multi-agent and multi-view settings. We present WorldWeaver (W^2), a streaming multi-agent video diffusion model that augments rollout with cross-agent world state registers: learnable tokens that store shared world information, track individual agent status, and are dynamically updated after each generated chunk. We ground these registers with supervision signals spanning individual agent status, global state views including bird's-eye views, and scene text. We further improve the architecture with a Mixture-of-Transformers design that uses separate weights for world state modeling and visual frame modeling. Extensive experiments in two-agent Minecraft video generation show that explicit world-state modeling improves logical consistency and generation quality.

## 2. 方法论
- **核心思想**：引入**跨智能体世界状态寄存器**（World State Registers, WSR），一组可学习的标记（tokens），用于持久存储共享世界信息，并在生成每个新帧后动态更新。
- **关键技术细节**：
  - **寄存器设计**：每个时间步的寄存器 \( r_i \) 存储全局布局、智能体状态等信息，在因果注意力中位于帧之间（顺序为 \( [x_0, r_0, x_1, r_1, \dots] \)），使得下一帧能依赖前一时刻的寄存器。
  - **三阶段训练课程**：
    1. **Stage 1（双向训练）**：基于Solaris的双向检查点微调，训练多智能体教师模型，学习跨智能体场景结构。
    2. **Stage 2（因果训练）**：将教师转换为因果学生，采用流匹配损失 + 寄存器监督损失（包括智能体状态、鸟瞰图、场景文本）。使用局部注意力窗口（W=6）。
    3. **Stage 3（自强制训练，Self-Forcing）**：模拟推理时的滚动生成，让学生模型在自己的预测帧和状态上训练，采用DMD分布匹配损失 + 状态损失，缓解训练-测试不匹配。
  - **混合Transformer（MoT）架构**：为世界状态标记和视觉帧标记配备独立的权重（投影层、FFN、归一化等），但在注意力机制中共同计算。消除两类目标（状态更新 vs 视觉生成）之间的参数竞争。

## 6. 主要结论与发现
- 显式世界状态建模（寄存器）**显著提升**了多智能体视频逻辑一致性和视觉质量，WorldScore从81.0提升至105.1。
- 寄存器即使没有监督也能带来提升（WorldScore 93.8），但添加监督信号（尤其组合）性能最优（105.1），其中场景文本监督效果最强。
- MoT架构在寄存器含有丰富语义时优于Dense架构，分离状态与视觉分支减少了目标冲突。
- 半监督训练中，增加未标注数据可进一步提高生成质量，为现实场景（缺乏完整状态标注）提供了可行路径。
- 自强制阶段继续训练（3-4K步）可进一步提升VLM准确率（65.8→68.1），尤其是冻结视觉分支后只更新寄存器参数。

## 7. 优点
- **创新性**：首次在视频扩散模型中引入可学习的、跨智能体共享的世界状态寄存器，并提供动态更新机制。
- **方法论系统性**：三阶段训练课程（双向→因果→自强制）逐步构建稳定滚动生成，并配合自强制解决累积误差。
- **架构设计**：MoT解耦状态和视觉生成，避免参数竞争，适用于多种监督组合。
- **监督多样性**：从局部（agent stats）到全局（BEV）再到语义（scene text），覆盖世界状态的不同方面。
- **可解释性**：世界状态寄存器可直接解码为可视化信息（坐标、BEV地图、文本描述），便于检查和验证一致性。
- **半监督扩展**：为真实世界有限状态标注场景提供了实用方向。

## 8. 不足与局限
- **实验场景单一**：仅评估了两智能体Minecraft环境，缺乏对更多智能体数量、更复杂环境（如3D物理、非网格世界）的验证。
- **状态监督依赖仿真器**：智能体状态和鸟瞰图在真实世界中难以获取，限制方法直接迁移到现实数据。
- **未报告显式算力成本**：缺少GPU类型、训练时间、推理速度等细节，难以评估可复现性和计算开销。
