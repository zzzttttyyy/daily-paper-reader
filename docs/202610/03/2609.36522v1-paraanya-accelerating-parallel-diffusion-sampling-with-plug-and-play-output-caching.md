## 摘要
扩散模型在生成任务中取得了显著成功，但其固有的串行采样过程带来了严重的计算瓶颈。最近的并行时间（Parallel-in-Time, PinT）求解器试图通过在时间步滑动窗口上并行生成来缓解这一问题，仅当逐步变化趋于稳定时才推进窗口。然而，这种重叠窗口机制迫使网络重复评估相同的时间步。当迭代之间的输入变化极小时，这些冗余评估会导致显著的计算浪费。为了解决这一低效问题，我们提出了 ParaAnya，一种与并行采样算法无关的输出缓存机制，能够减少函数评估次数（NFE）。ParaAnya 缓存扩散模型的输入-输出对，并在重叠时间步上复用缓存的输出。通过仅将缓存未命中的时间步分派给 GPU 工作进程，我们的方法消除了冗余计算，同时保留了底层算法更新规则的结构。我们将 ParaAnya 集成到四种代表性的并行采样算法中，并在 Stable Diffusion v1.5 上评估其性能。在八块 GPU 上使用 DDIM 评估的四种并行采样器中，ParaAnya 相比其无缓存版本提供了 1.30--2.43 倍的加速，并将 NFE 最多减少 70.1%，相比单 GPU 串行采样最高实现 5.62 倍加速，同时保持相当的 CLIP 分数。

## Abstract
Diffusion models have achieved remarkable success in generative tasks, but their inherently sequential sampling process introduces a severe computational bottleneck. Recent Parallel-in-Time (PinT) solvers attempt to mitigate this by parallelizing generation across a sliding window of timesteps, advancing the window only when step-wise changes stabilize. However, this overlapping window mechanism forces the network to repeatedly evaluate the same timesteps. When the input variations between iterations are minimal, these redundant evaluations lead to significant computational waste. To address this inefficiency, we propose ParaAnya, an output cache mechanism agnostic to the parallel sampling algorithm that can reduce the number of function evaluations (NFE). ParaAnya caches input-output pairs of diffusion models and reuses the cached output at overlapping timesteps. By dispatching only cache-miss timesteps to GPU workers, our approach eliminates redundant computation while preserving the structure of the underlying algorithms' update rules. We integrate ParaAnya into four representative parallel sampling algorithms and evaluate its performance on Stable Diffusion v1.5. Across four parallel samplers evaluated with DDIM on eight GPUs, ParaAnya provides $1.30$--$2.43\times$ speedups over their uncached counterparts and reduces NFE by up to 70.1\%, reaching up to a $5.62\times$ speedup over single-GPU serial sampling while maintaining comparable CLIP scores.

# ParaAnya 论文总结

## 1. 核心问题与研究背景

- **扩散采样的串行瓶颈**：扩散模型生成质量依赖去噪步数，而采样过程本质串行（每一步依赖上一步），单样本延迟难以通过常规批推理降低。
- **PinT（Parallel-in-Time）求解器的思路与代价**：ParaDiGMS、ParaTAA、ParaSolver（Picard 迭代类）与 SRDS（Parareal 类）沿时间维并行，用滑动窗口同时估计多个时间步并迭代精化；窗口仅在领先状态收敛后才推进。
- **核心痛点——重叠窗口导致冗余评估**：窗口推进时同一时间步被反复送入网络，迭代间输入 latent 变化很小时，这些重复前向几乎是纯浪费。
- **作者的实证依据**：对 100 步 DDIM、30 个 prompt 做 profiling，发现 **39.93%** 的 drift 评估属于"重访同一时间步且平均 latent 变化 < 0.05"，说明冗余占比很高。
- **整体含义**：论文主张 PinT 中相当一部分网络评估并非并行化的必要成本，而是可被系统级缓存消除的冗余，且无需重训练模型或改动算法更新规则。

## 2. 方法论：ParaAnya 输出缓存

- **核心思想**：在 drift 评估（`s_θ`）之前插入一个与并行算法无关的输出缓存，缓存"时间步 → (输入 latent, 网络输出)"的映射，当当前 latent 与缓存输入足够接近时直接复用缓存输出。
- **缓存结构**：协调器维护 `C: t ↦ (x̂_t, ε̂_t)`，其中 `ε̂_t = ε_θ(x̂_t, t)`，保证缓存中存的输出与其输入严格对应（缓存不变量）。
- **相似性度量**：用逐元素 ℓ1 范数除以 latent 维度 D 得到每坐标平均绝对偏差 `δ_t^k = (1/D)·‖x_t^k − x̂_t‖_1`，使阈值 `τ_cache` 在不同 latent 分辨率下可比。
- **命中/未命中划分**：首次进入窗口的时间步视为 miss；其余按 `δ_t^k < τ_cache` 划入命中集 `H^k`，否则进入 miss 集 `M^k`。
- **输出装配与派发**：命中处直接用 `ε̂_t`，未命中处调用 `ε_θ(x_t^k, t)`；**只有 miss 被派发到 GPU worker，并在一次批前向中统一评估**。
- **缓存更新**：仅对 miss 更新 `C[t] ← (x_t^k, ε_t^k)`，从而始终维持不变量。
- **与算法的关系**：缓存只提供网络输出，后续的 drift 计算、轨迹更新、收敛判定与窗口推进仍完全沿用原算法规则，因此是"即插即用"且对 Picard 类与 Parareal 类（粗/细求解器中的重复评估）同样适用。
- **与 DeepCache 的区别**：DeepCache 复用相邻去噪时间步的信息，ParaAnya 复用的是**同一时间步在不同 PinT 迭代之间的冗余**。

## 6. 主要结论与发现

- **一致加速**：将 ParaAnya 集成到 4 个 PinT 方法后，在所有测试的 DDIM 步数下 wall-clock 加速比均匹配或优于无缓存版本，相对无缓存版本提升 **1.30–2.43×**。
- **NFE 大幅下降**：NFE 最多减少 **70.1%**；相对单 GPU 串行采样最高达到 **5.62×** 加速（ParaTAA，N=100）。
- **质量基本保持**：CLIP 分数变化很小，SRDS 上几乎为零。
- **窗口大小并非越大越好**：存在并行度与收敛成本的权衡；DDPM 下两方法均在 P=64 最优、P=128 回落；DDIM 下 ParaSolver 最优 P=8，ParaAnya 最优 P=16。
- **容差是可调旋钮**：τ_cache 增大持续提升命中率、降低迭代数与 NFE；但过小容差（0.001/0.005）因复用有限反而比无缓存更慢。τ_cache=0.01 开始转为净收益（2.01×），τ_cache=0.05 给出 3.08× 且 CLIP 不降，τ_cache=0.1 最快（3.56×）但 CLIP 略降至 31.19。
- **硬件扩展性**：所有方法加速比随 GPU 数增加而提升；多个基座方法在 1–2 GPU 时甚至慢于串行（如 ParaSolver 单 GPU 仅 0.41×），加入 ParaAnya 后单 GPU 提升至 1.02×，8 GPU 时 ParaDiGMS 1.25×→3.13×、ParaSolver 1.90×→3.70×、ParaTAA 2.31×→3.79×。

## 7. 优点

- **即插即用、算法无关**：不改动底层更新规则、不重训练，可同时适配 Picard 与 Parareal 两类框架，通用性强。
- **问题定位清晰且有量化依据**：先用 profiling（39.93% 冗余评估）量化动机，再给出解决方案，逻辑闭环。
- **设计细节严谨**：以 ℓ1 均值归一化使阈值跨分辨率可比；缓存不变量保证 `ε̂_t = ε_θ(x̂_t, t)`；仅对 miss 更新缓存；miss 合并为单次批前向，兼顾正确性与吞吐。
- **实验对照规范**：配对种子与初始噪声、统一 warm-up、固定超参，跨方法/步数/GPU 数交叉验证。
- **工程可复现**：代码已开源；容差扫描提供了可直接落地的超参选择建议。
