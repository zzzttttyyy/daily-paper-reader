## 摘要
基于扩散的世界模型能够生成高质量的交互式环境，但由于去噪过程中反复进行 Transformer 评估，其推理开销巨大。现有缓存方法主要利用特征级或 token 级的时间冗余，尚未充分挖掘扩散特征潜在的数学结构。在本工作中，我们发现世界模型特征在相邻去噪步之间具有高度稳定的奇异子空间，而其奇异值则遵循可预测的演化模式。基于这一观察，我们提出了 SpectralCache，一种无需训练的谱缓存框架，它复用稳定的奇异子空间，并仅通过线性外推估计低维奇异值。我们进一步利用相邻完整计算特征之间的谱一致性，通过奇异值缩放跳过部分昂贵的骨干网络评估。在代表性世界模型上的大量实验表明，SpectralCache 在保持生成质量的同时持续提升推理效率。在 HunyuanWorld-Voyager-13B 上，SpectralCache 实现了 5.22 倍加速，并在静态场景下保持 65.90 的 WorldScore，在推理效率上大幅优于现有的无需训练缓存方法。

## Abstract
Diffusion-based world models enable high-quality interactive environment generation but suffer from substantial inference overhead due to repeated Transformer evaluations during denoising. Existing caching methods mainly exploit temporal redundancy at the feature or token level, leaving the underlying mathematical structure of diffusion features largely unexplored. In this work, we reveal that world-model features exhibit highly stable singular subspaces across nearby denoising steps, while their singular values follow predictable evolution patterns. Building on this observation, we propose SpectralCache, a training-free spectral caching framework that reuses stable singular subspaces and estimates only low-dimensional singular values through linear extrapolation. We further exploit the spectral consistency between neighboring full-computation features to skip selected expensive backbone evaluations via singular value scaling. Extensive experiments on representative world models demonstrate that SpectralCache consistently improves inference efficiency while preserving generation quality. On HunyuanWorld-Voyager-13B, SpectralCache achieves 5.22x acceleration while maintaining a WorldScore of 65.90 for static scenes, substantially outperforming existing training-free caching methods in inference efficiency.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：
  - 对 DiT 最终层视觉特征做低秩 SVD，将其拆分为奇异子空间、奇异值和残差。
  - 相邻去噪步之间，主导奇异子空间高度稳定，因此可复用；奇异值则可通过线性外推或常数缩放估计。
  - 只在必要时进行完整 DiT 计算，其余步仅更新低维奇异值并重建特征，从而跳过昂贵骨干评估。

- **关键观察**：
  - **低秩性**：视觉特征能量集中在少数奇异值上，前 128 个奇异值平均捕获约 96% 能量。
  - **子空间稳定**：相邻去噪步的主导 U、V 子空间余弦相似度大多高于 0.95，时间间隔可达 8 步。
  - **奇异值线性外推**：对步骤 \(m < n < p\)，有近似  
    \[
    \operatorname{diag}(\hat{\Sigma}_p) \approx \operatorname{diag}(\Sigma_n) + \frac{p-n}{n-m}\bigl(\operatorname{diag}(\Sigma_n)-\operatorname{diag}(\Sigma_m)\bigr)
    \]
    经验误差约 0.71%。
  - **相邻全计算步奇异值近似常数缩放**：两个相近全计算步的奇异值范数比接近常数，实验取 \(\gamma=1.1\)。

- **方法流程**：
  - 将第 \(t\) 步最终层视觉特征 \(F_t\) 重塑为 \(X_t \in \mathbb{R}^{M \times D}\)，做 rank-\(r\) SVD：  
    \(X_t = U_t^r \Sigma_t^r (V_t^r)^\top + R_t\)，缓存谱状态 \(Q_t=\{U_t^r,\Sigma_t^r,V_t^r,R_t\}\)。默认 \(r=128\)，仅保留最近两个全计算步的谱状态。
  - **完整计算步**：正常执行 DiT 骨干，得到特征并做 SVD 缓存。
  - **近似步**：跳过 DiT 骨干，复用最近全计算步的子空间和残差，只估计奇异值：
    \[
    \hat{X}_t = U_n^r \hat{\Sigma}_t^r (V_n^r)^\top + R_n
    \]
  - **线性外推估计**：连续缓存步中，用最近两个全计算步 \(m,n\) 外推当前步 \(t\)：
    \[
    \hat{\Sigma}_t^r = \Sigma_n^r + \beta_t(\Sigma_n^r-\Sigma_m^r),\quad \beta_t=\frac{t-n}{n-m}
    \]
  - **缩放估计**：当缓存触发刷新但可跳过全计算时，用
    \[
    \hat{\Sigma}_t^r = \gamma \Sigma_n^r,\quad \gamma=1.1
    \]
  - **误差触发机制**：累积混沌 token 的曲率加权近似误差 \(E_{\text{acc}}\)，若超过阈值 \(\tau\) 或缓存间隔达到 \(N\)，则触发刷新。刷新时交替使用全计算或缩放近似，以进一步减少全计算次数。
  - **整体策略**：先执行两个全计算步初始化缓存；之后在“外推近似步—触发刷新—缩放近似/全计算”之间动态切换。
